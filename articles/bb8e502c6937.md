## 導入：量子回路を学習可能なモデルへ
量子機械学習（QML）の核心は、量子回路のパラメータ（回転角など）を学習データに合わせて最適化することにあります。古典的なニューラルネットワークでは重みを更新するように、量子回路においてはゲートに適用される回転角を、勾配降下法などの最適化アルゴエズムを用いて調整します。

本記事では、Qiskitを用いて、量子回路のパラメータを学習させる「量子回路学習（Quantum Circuit Learning: QCL）」の基礎的な実装手順を解説します。

## 量子回路学習の基本構成
量子回路学習は、以下のステップで構成されます。

1. データのエンコーディング：古典データを量子状態（量子ビットの振幅や位相）に変換する。
2. 学習可能な量子回路（Ansatz）：パラメータ $\theta$ を持つ量子回路。
3. 測定とコスト関数：測定結果から得られる期待値を計算し、正解ラベルとの差異（コスト）を算出する。
4. 最適化：コストを最小化するようにパラメータ $\theta$ を更新する。

## 実装：パラメータ最適化のプロセス
ここでは、単純な2量子ビットの回路を用い、特定のラベル（0または1）を分類できるようにパラメータを最適化するコードを実装します。

```python
import numpy as np
from qiskit import QuantumCircuit
from qiskit.circuit import Parameter
from qiskit_algorithms.optimizers import COBYLA
from qiskit_algorithms import NeuralNetworkClassifier
from qiskit.primitives import Sampler
from qiskit.visualization import plot_histogram

# 1. パラメータの定義
theta = Parameter('θ')

# 2. 量子回路（Ansatz）の構築
# 入力データ（エンコーディング）と学習可能パラメータを組み合わせた回路
def create_ansatz(data_val):
    qc = QuantumCircuit(2)
    # データのエンコーディング（角度エンコーディング）
    qc.ry(data_val, 0)
    qc.rz(data_val, 1)
    # 学習可能なパラメータの適用
    qc.rx(theta, 0)
    qc.ry(theta, 1)
    qc.cx(0, 1)
    return qc

# 3. 学習用データの準備
# 2次元の入力データ（例：角度）とそのラベル
X = np.array([[0.1, 0.2], [1.5, 1.6], [3.0, 3.1], [4.5, 4.6]])
y = np.array([0, 1, 0, 1])

# 4. 量子回路学習の準備
# ここでは簡略化のため、特定の回路構造を固定した形式でシミュレート
sampler = Sampler()
optimizer = COBYLA(maxiter=50)

# 実際のQML実装では、Qiskit Machine Learningのクラスを利用するのが効率的です
from qiskit_machine_learning.algorithms import NeuralNetworkClassifier
from qiskit_machine_learning.circuit.library import RawFeatureMap, ZZFeatureMap

# 特徴マップ（Encoding）とAnsatz（Ansatz）の分離
feature_map = ZZFeatureMap(feature_dimension=2, reps=1)
ansatz = QuantumCircuit(2)
ansatz.rx(theta, 0)
ansatz.ry(theta, 1)

# 構成要素を統合した回路の作成
full_circuit = feature_map.compose(ansatz)

# 分類器の設定
qnn = NeuralNetworkClassifier(
    neural_network=None, # 実際には構築した回路を渡す
    optimizer=optimizer,
    sampler=sampler
)

# 注：上記は概念的な流れを示すための構造です。
# 実際に動かす際は、Qiskit Machine Learningの回路定義に基づいた
# 期待値計算（Expectation Value）の定義が必要です。
```

## 勾配計算の重要性：Parameter Shift Rule
量子回路のパラメータ最適化において、古典的な自動微分（Backpropagation）を量子回路に直接適用することは困難です。なぜなら、量子測定は確率的な出力であり、中間層の微分値を直接取得できないためです。

ここで用いられるのが「Parameter Shift Rule（パラメータ・シフト則）」です。これは、パラメータ $\theta$ を $\theta + \pi/2$ と $\theta - \pi/2$ にずらして2回測定を行い、その差分をとることで、量子回路の勾配を正確に計算する手法です。

## 実装のポイント：コスト関数の最小化
学習の成否は、コスト関数の設計に依存します。
- 回帰タスク：平均二乗誤差（MSE）
- 分類タスク：クロスエントロピー誤差

最適化アルゴリズムには、勾配情報を用いない「COBYLA」や、パラメータ・シフト則を用いた「SPSA（Simultaneous Perturbation Stochastic Approximation）」が、量子ノイズの影響を考慮する上でよく利用されます。

## まとめ
量子回路学習は、量子回路を「重みを持つ層」として扱い、古典的な最適化手法を用いてパラメータをチューニングする手法です。この手法を応用することで、量子計算の強みである高次元特徴量の表現力を活用した機械学習モデルの構築が可能になります。
