AI×量子コンピューティングの実装において、単一の量子ゲート操作を理解した次のステップは、それらを組み合わせて「計算のフロー」を構築することです。

単一ゲート（HadamardやPauliゲート）による状態の準備、そしてCNOTゲートによる量子もつれの生成。これらを論理的な順序で配置することで、初めて量子アルゴリズムとしての意味を持つ回路が形成されます。本記事では、複数のゲートを組み合わせた回路構成のコード実装を通じ、回路設計の基礎を解説します。

## ゲートの組み合わせによる回路設計の基本

量子回路の設計は、以下の3つのフェーズの連続として捉えることができます。

1. **初期状態の準備**: すべての量子ビットを $|0\rangle$ 状態に初期化する。
2. **ユニタリ変換（演算）**: Hadamardゲートなどで重ね合わせを作り、回転ゲートや制御ゲートを用いて計算ロジックを適用する。
3. **測定**: 演算後の量子状態を古典的なビット列として取り出す。

これらを組み合わせた、より複雑な回路の構成例をQiskitを用いて見ていきましょう。

## 実装：多量子ビット回路の構築

ここでは、2つの量子ビットを用い、「重ね合わせの生成」→「量子もつれの生成」→「位相の回転」という一連のプロセスを実装します。

```python
from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator
from qiskit.visualization import plot_histogram

# 1. 回路の初期化（2量子ビット、2古典ビット）
qc = QuantumCircuit(2, 2)

# 2. フェーズ1：重ね合わせの生成
# 0番目の量子ビットにHadamardゲートを適用
qc.h(0)

# 3. フェーズ2：量子もつれの生成（CNOTゲートの適用）
# 0番目を制御ビット、1番目を標的ビットとする
qc.cx(0, 1)

# 4. フェーズ3：位相の回転操作（Rzゲートによる制御）
# 量子状態に位相の変化を付与する
qc.rz(0.5, 0)
qc.rz(0.5, 1)

# 5. 測定フェーズ
# 量子ビットの状態を古典ビットへ写像
qc.measure([0, 1], [0, 1])

# シミュレータの準備
simulator = AerSimulator()

# 回路の実行
job = simulator.run(qc, shots=1024)
result = job.result()

# 結果の取得
counts = result.get_counts(qc)
print("測定結果:", counts)

# 回路の構成を確認（テキスト形式で出力）
print("\n--- Circuit Diagram ---")
print(qc.draw(output='text'))
```

## コードの解説と制御フローのポイント

### ゲートの連鎖と計算の依存関係
上記のコードでは、`qc.h(0)` の後に `qc.cx(0, 1)` を配置しています。この「順序」が極めて重要です。もし `cx` ゲートを `h` ゲートの前に配置してしまった場合、制御ビットが $|0\rangle$ のままであるため、量子もつれ（Entanglement）は生成されません。

### 回転ゲート（Rz）によるパラメータ化
`qc.rz(0.5, 0)` のように回転ゲートを組み合わせることで、回路に「パラメータ」を持たせることが可能になります。これは、将来的にVQE（Variational Quantum Eigensolver）のような、古典最適化ループと連携する量子・古典ハイブリッドアルゴリズムを実装する際の基礎となります。

### 測定による情報の抽出
`qc.measure([0, 1], [0, 1])` は、量子的な重ね合わせ状態を、私たちが扱える古典的な `0` または `1` の値へと崩壊（Collapse）させるプロセスです。ここまでのゲート操作がどれほど複雑であっても、最終的に得られるのは確率分布に基づいたビット列です。

## まとめ

量子回路の構築は、単一ゲートの習得から、それらを論理的な順序で繋ぎ合わせる「回路設計」へと進化します。ゲートの組み合わせによって、量子ビット間に相関（もつれ）を生み出し、位相を制御することで、量子コンピュータ特有の計算能力を引き出すことが可能になります。
