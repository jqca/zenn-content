## 導入：量子アニーリングとQAOA
組み合わせ最適化問題は、物流のルート最適化やシフト作成など、実社会の多くの課題に直結しています。量子アニーリング（Quantum Annealing）は、量子トンネル効果を利用してエネルギーの最小状態を探る手法として期待されています。

一方で、現在主流となっているゲート型量子コンピュータ（NISQデバイス）において、アニーリングに近い性質を持つ最適化アルゴマンとして注目されているのが「QAOA（Quantum Approximate Optimization Algorithm）」です。QAOAは、変分量子回路（VQC）の一種であり、古典的な最適化ループと量子回路を組み合わせたハイブリッドアルゴリズムです。

本記事では、最も基本的な組み合わせ最適化問題の一つである「MAX-CUT問題」を題材に、Qiskitを用いたQAOAの実装プロセスを解説します。

## MAX-CUT問題の定式化
MAX-CUT問題とは、グラフの各頂点を2つのグループ（カット）に分けたとき、異なるグループに属する頂点間を結ぶエッジ（枝）の数を最大化する問題です。

この問題を、量子回路で扱える「コストハミルトニアン（$H_C$）」の形式に変換する必要があります。各頂点 $i$ に対して、グループ $s_i \in \{1, -1\}$ を割り当てると、コスト関数は以下のように記述できます。

$$C(s) = \sum_{(i,j) \in E} \frac{1}{2}(1 - s_i s_j)$$

この式を最小化（あるいは最大化）する問題として、量子回路のパラメータに落とし込んでいきます。

## QAOAのアルゴリズム構造
QAOAは、以下の2つのユニタリ演算子を交互に適用し、その回数（レイヤー数 $p$）を増やしながら最適化を進めます。

1. **コスト・ユニタリ演算子 ($U(H_C, \quad \gamma)$)**: コストハミルトニアンに基づいた位相回転。
2. **ミキシング・ユニタリ演算子 ($U(H_B, \quad \beta)$)**: 状態を混合させ、探索範囲を広げるための演算。

回路の最終的な状態は、初期状態（すべて$|0\rangle$）から、$\gamma$ と $\beta$ というパラメータを用いて、
$$|\psi(\vec{\gamma}, \vec{\beta})\rangle = U(H_B, \beta_p) U(H_C, \gamma_p) \dots U(H_B, \beta_1) U(H_C, \gamma_1) |0\rangle^{\otimes n}$$
として構成されます。

## 実装：QiskitによるQAOA
以下に、PythonとQiskitを用いた実装コードを示します。

```python
import numpy as np
import networkx as nx
from qiskit import QuantumCircuit
from qiskit.circuit import Parameter
from qiskit_algorithms import QAOA
from qiskit_algorithms.optimizers import COBYLA
from qiskit_optimization.applications import Maxcut
from qiskit_aer import AerSimulator
from qiskit.primitives import Estimator

# 1. グラフの定義（MAX-CUT対象）
graph = nx.Graph()
graph.add_edges_from([(0, 1), (1, 2), (2, 3), (3, 0), (0, 2)])

# 2. MAX-CUT問題のインスタンス化
maxcut = Maxcut(graph)
operator, offset = maxcut.to_ising(expr_format='pauli')

# 3. プリミティブ（Estimator）と最適化器の準備
estimator = Estimator()
optimizer = COBYLA(maxiter=100)

# 4. QAOAの構築
qaoa = QAOA(estimator=estimator, optimizer=optimizer, reps=2)

# 5. 実行と最適化
result = qaoa.compute_minimum_eigenvalue(operator)

# 6. 結果の解釈
# 最終的な期待値を計算して、最適なカットを確認
with ASEstimator() as est:
    expectation_value = est.run(qaoa.circuit, operator).result().values[0]

print(f"最適化されたコスト関数の期待値: {expectation_value}")

# 7. グラフの分割結果を可視化
# 最適化されたパラメータを用いて、解をサンプリングするプロセス
# (ここでは簡略化のため、計算された期待値の論理的な分割を想定)
```

## 実装のポイント
### コストハミルトアンの変換
`maxcut.to_ising(expr_format='pauli')` を使用することで、グラフ理論の制約条件を、量子ビットの $Z$ 演算子の積（Pauli $Z$ 演算子の組み合わせ）へと自動的に変換しています。これにより、実装者が複雑なハミルトニアンの構築を意識せずに済みます。

### 変分パラメータの最適化
本実装では `COBYLA` を使用しています。これは勾配を必要としない（Gradient-free）最適化手法であり、量子デバイスのノイズに対して比較的頑健な特性を持っています。`reps=2` とすることで、コスト演算子とミキシング演算子の交互適用回数を設定しています。

## 実行結果の考察
実際に上記のコードを動作させると、エッジの重みが等価なグラフにおいて、カットの数（エッジの分割数）を最大化するパラメータ $\gamma, \beta$ が探索されます。

計算量については、量子ビット数 $n$ に対して、エッジ数 $|E|$ に依存する項が含まれますが、ゲート型量子コンピュータの回路深さはレイヤー数 $p$ に比例して増加します。NISQデバイスの制約上、深すぎる回路（大きな $p$）はノイズの影響を強く受けるため、実用的な $p$ の選択が課題となります。
