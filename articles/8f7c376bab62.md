=== 導入 ===
量子コンピュータの計算資源を機械学習に活用する「量子機械学習」の分野において、パラメータ付き量子回路（PQC）を用いた手法は、現在のNISQ（Noisy Intermediate-Scale Quantum）デバイスにおいて最も有力なアプローチの一つです。

その中でも、量子回路のパラメータを学習可能な重みとして扱い、古典的な最適化アルゴリズムを用いて損失関数を最小化していく「量子回路学習（Quantum Circuit Learning: QCL）」は、古典的なニューラルネットワークの概念を量子回路に拡張したものです。

本記事では、PythonとQiskitを用い、量子回路学習の仕組みを理解するための最小構成の分類器を実装します。データのエンコーディングから、パラメータ更新のプロセスまで、手を動かせる粒度で解説します。

=== 量子回路学習の構成要素 ===
量子回路学習は、主に以下の3つのステップで構成されます。

1. **データ・エンコーディング（Feature Map）**
古典的なデータ（ベクトル $\vec{x}$）を、量子状態 $|\psi(\vec{x})\longrightarrow$ 角度量子化などを通じて量子ビットの回転角へと変換し、量子状態にマッピングします。

2. **パラメータ付き量子回路（Ansatz）**
学習可能なパラメータ $\theta$ を持つ量子回路です。この回路の構造（回転ゲートの組み合わせなど）を、学習によって最適化していきます。

3. **測定とコスト関数（Measurement & Cost Function）**
回路の出力（期待値）を測定し、正解ラベルとの乖離を計算します。このコスト関数を最小化するように、古典的な最適化器（Gradient Descentなど）がパラメータ $\theta$ を更新します。

=== 実装：量子分類器の構築 ===
今回は、2次元の入力データを、1つの量子ビットを用いた量子回路で分類するタスクを実装します。

```python
import numpy as np
from qiskit import QuantumCircuit
from qiskit.circuit import Parameter
from qiskit_algorithms.optimizers import GradientDescent
from qiskit_aer import AerSimulator
from qiskit.primitives import Estimator

# 1. データの準備（2次元データの生成）
# クラス0: 原点付近, クラス1: 遠方
X = np.array([[0.1, 0.1], [0.2, 0.1], [0.1, 0.2], [0.8, 0.8], [0.9, 0.7], [0.7, 0.9]])
y = np.array([0, 0, 0, 1, 1, 1])

# 2. 量子回路（Ansatz + Feature Map）の定義
theta = Parameter('θ')
phi = Parameter('φ')

def create_circuit(x_data):
    qc = QuantumCircuit(1)
    # Feature Map: データを量子状態にエンコード
    qc.ry(x_data[0], 0)
    qc.rz(x_data[1], 0)
    # Ansatz: 学習可能なパラメータを持つ回転ゲート
    qc.ry(theta, 0)
    qc.rz(phi, 0)
    return qc

# 3. コスト関数の定義
def cost_function(params, X, y):
    # params = [theta, phi]
    estimator = Estimator()
    loss = 0
    for i in range(len(X)):
        qc = create_circuit(X[i])
        # 回路のパラメータを更新
        qc.assign_parameters({theta: params[0], phi: params[1]})
        # Z基底での期待値を計算
        expectation_value = estimator.run(qc, QuantumCircuit(1)).result().values[0]
        # 二乗誤差の累積
        loss += (expectation_value - y[i])**2
    return loss / len(X)

# 4. 学習の実行
initial_params = np.array([0.1, 0.1])
optimizer = GradientDescent(maxiter=50)

# 学習プロセス（シミュレータ上で実行）
# 注意: 実際の実行環境では、Estimatorの挙ティブに依存します
result = optimizer.minimize(fun=cost_function, x0=initial_params, args=(X, y))

optimized_params = result.x
print(f"Optimized parameters: {optimized_params}")
```

=== コードの解説 ===

#### データ・エンコーディングの役割
`qc.ry(x_data[0], 0)` の部分では、入力データの第1成分を $y$ 軸周りの回転角として適用しています。これにより、古典的な数値が量子状態の振幅や位相として量子ビットに刻み込まれます。

#### 学習パラメータの役割
`theta` と `phi` は、データがエンコードされた後の量子状態を「分類しやすい位置（測定結果が0または1に寄りやすい状態）」へ動かすための調整弁です。

#### コスト関数の計算
`Estimator` を使用して、量子回路の出力（期待値 $\langle Z \rangle$）を算出しています。この値は $-1$ から $1$ の範囲で返されます。ラベル $y=0$ に対しては期待値が $1$ に近づき、$y=1$ に対しては $-1$ に近づくように、古典的な最適化器がパラメータを更新していきます。

=== 実装上の注意点と考察 ===
本実装では、計算コストを抑えるために `qiskit-aer` のシミュレータを使用しています。

1. **パラメータの数と回路の深さ**
パラメータ $\theta$ が増えると表現力は上がりますが、回路が深くなり、ノイズの影響（NISQにおける課題）を受けやすくなります。

2. **エンコーディングの選択**
今回は単純な `ry`, `rz` を用いましたが、より複雑なデータ構造（画像など）を扱う場合は、`ZZFeatureMap` のような高次の相関を考慮したエンコーディングが検討されます。

3. **収束性**
`GradientDescent` は局所解に陥る可能性があります。より複雑な問題では、`SPSA` (Simultaneous Perturbation Stochastic Approximation) のような、ノイズに強い最適化アルゴリズムの採用が実用的です。
