量子コンピュータのアルゴリズムを設計する際、周期性の検出や位相の推定、あるいは量子振幅増幅の基盤となる演算として、量子Fourier変換（QFT）の理解は不可欠です。古典的な離散フーリエ変換（DFT）が信号の周波数成分を抽出するように、QFTは量子状態の振幅に埋め込まれた位相情報を操作するための強力な道具となります。

本記事では、QFTの数学的な仕組みを整理し、Qiskitを用いて実際に量子回路を構築・実行する手順を解説します。

## 量子Fourier変換（QFT）の仕組み

QFTは、計算基底状態 $|j\rangle$ を、位相が回転した状態の重ね合わせへと変換する演算です。$n$ 個の量子ビットを用いる場合、基底 $|j\rangle$（$j \in \{0, 1, \dots, 2^n-1\}$）は、以下のような位相の回転を伴う状態に変換されます。

$$|j\rangle \to \frac{1}{\sqrt{2^n}} \sum_{k=0}^{2^n-1} e^{2\pi i j k / 2^n} |k\rangle$$

この変換の核心は、各量子ビットの位相に、そのビットの重み（位）に応じた回転を加える点にあります。具体的には、制御位相回転ゲート（$CP$ゲート）を用いて、上位ビットの情報を下位ビットの位相へ転写していく操作を繰り返します。

## QiskitによるQFT回路の実装

それでは、実際にQiskitを用いて、任意のビット数に対応できるQFT回路を実装してみましょう。QFTの構成要素は、アダマールゲート（$H$）と、制御位相回転ゲート（$CP$）の組み合わせです。

```python
import numpy as np
from qiskit import QuantumCircuit
from qiskit.circuit.library import QFT

def create_qft_circuit(n_qubits):
    """
    n_qubits個の量子ビットを用いたQFT回路を作成する
    """
    qc = QuantumCircuit(n_qubits)
    
    for i in range(n_qubits):
        # 各量子ビットにアダマールゲートを適用
        qc.h(i)
        
        # 下位のビットに対して制御位相回転ゲートを適用
        for j in range(i + 1, n_qubits):
            # 回転角は 2*pi / 2^(j-i+1)
            angle = np.pi / (2**(j - i))
            qc.cp(angle, j, i)
            
    # 回路の見栄えのためにビットの順序を反転させる（QFTの標準的な手続き）
    # 実際の実装では、QFTの結果はビット順が逆転して出力されるため、
    # 最後に量子ビットの順序を入れ替える操作が必要になることが多い。
    return qc

# 3量子ビットのQFT回路を生成
n = 3
qft_circuit = create_qft_circuit(n)

# 回路の可視化
print(qft_circuit.draw())
```

### コードの解説

1. **アダマールゲートの適用**: 各量子ビットに対して $H$ ゲートを適用することで、基底状態を重ね合わせ状態にします。
2. **制御位相回転ゲート（$CP$）**: 既に処理したビット（$i$）に対して、後続のビット（$j$）を制御変数とした位相回転を加えます。回転角は、ビット間の距離（重み）に応じて指数関数的に減少していきます。
3. **計算量**: $n$ 量子ビットのQFTのゲート数は $O(n^2)$ です。これは古典的なDFTの $O(n 2^n)$ と比較して、量子的な並列性を活かした極めて効率的な演算であることを示しています。

## 動作確認：特定の数値のエンコード

QFTが正しく動作しているかを確認するために、特定の数値を位相として埋め込んだ状態を作り、QFTを適用した後の期待値を確認します。

ここでは、単純化のために「回転」がどのように振幅に現れるかをシミュレーターで検証します。

```python
from qiskit_aer import AerSimulator
from qiskart import QuantumCircuit

def run_qft_verification(n_qubits):
    # 1. 回路の準備
    qc = QuantumCircuit(n_qubits)
    
    # 2. 初期状態として特定の位相を持つ状態を準備（例：すべて1の重ね合わせ）
    for i in range(n_qubits):
        qc.h(i)
    
    # 3. QFT回路の適用
    qft_gate = QFT(num_qubits=n_qubits)
    qc.append(qft_gate, range(n_qubits))
    
    # 4. 測定
    qc.measure_all()
    
    # 5. シミュレーターでの実行
    simulator = AerSimulator()
    job = simulator.run(qc, shots=1024)
    result = job.result()
    counts = result.get_counts()
    
    return counts

# 3量子ビットでの実行
results = run_qft_verification(3)
print("測定結果:", results)
```

実行結果として、入力した状態の周期性に対応する特定のビット列の頻度が高くなることが確認できれば、QFTが正しく位相を抽出できている証拠となります。
