=== 導入 ===
量子コンピュータのアルゴリズムを設計する際、古典的な機械学習手法では扱いきれない複雑な境界を持つデータに対して、量子的な特徴空間を活用する手法が注目されています。その代表的なアプローチの一つが「量子カーネル法」です。

量子カーネル法は、データを量子状態へとエンコードし、量子回路を用いて量子状態間の重なり（内積）を計算することで、高次元な特徴空間におけるカーネル行列を構成します。本記事では、PythonとQiskitを用い、古典的なデータ（角度データ）を量子状態に写像し、カーNEL行列を計算する具体的な実装プロセスを解説します。

=== 量子カーネル法の考え方 ===
古典的なサポートベクターマシン（SVM）などのカーネル法では、カーネル関数 $K(x, y)$ を用いて、低次元のデータを高次元の特徴空間への写像 $\phi(x)$ の内積として表現します。

$$K(x, y) = \langle \phi(x) | \phi(y) \rangle$$

量子カーネル法では、この写像 $\phi$ を量子回路 $U(x)$ によって実現します。具体的には、古典的な入力データ $x$ を量子ビットの回転角などのパラメータに変換し、量子ゲートを適用して量子状態 $|\psi(x)\エンジニア\rangle$ を生成します。この2つの量子状態の重なり（Fidelity）を測定することで、量子的なカーネル値を算出します。

=== 実装：量子特徴写像（Feature Map）の構築 ===
まずは、データを量子状態にエンコードするための「量子特徴写像」を実装します。ここでは、最も基本的な $ZZ$ Feature Mapを使用します。これは、単一ビットの回転（$R_z$）に加えて、ビット間の相関を表現する $R_{zz}$ ゲートを組み合わせたものです。

```python
import numpy as np
from qiskit import QuantumCircuit
from qiskit.circuit.library import ZZFeatureMap

def create_feature_map(num_qubits, data_point):
    """
    特定のデータポイントに対するZZFeatureMapを生成する
    """
    # ZZFeatureMapの定義
    feature_map = ZZFeatureMap(feature_dimension=num_qubits, reps=1)
    
    # データのエンコード（例：角度として適用）
    # 本来は回路のパラメータとして渡すが、
    # 実装の分かりやすさのため、直接的な回転をシミュレート
    circuit = QuantumCircuit(num_qubits)
    
    # 1. 各量子ビットへの基本回転
    for i in range(num_qubits):
        circuit.ry(data_point[i], i)
        
    # 2. ビット間の相互作用（ZZ相互作用の簡易実装）
    for i in range(num_qubits - 1):
        circuit.cx(i, i+1)
        circuit.rz(data_point[i] * data_point[i+1], i+1)
        circuit.cx(i, i+1)
        
    return circuit

# テストデータ（2量子ビット分）
data_x = [np.pi/4, np.pi/2]
data_y = [np.pi/2, np.int(np.pi)]

circuit_x = create_feature_map(2, data_x)
print("Feature Map Circuit X:")
print(circuit_x.draw())
```

=== 実装：量子カーネル行列の計算 ===
次に、2つのデータ点間のカーネル値（Fidelity）を計算するプロセスを実装します。これには、Swap Test、あるいは計算機リソースが許す場合は、2つの回路を重ね合わせた状態の期待値を計算する手法があります。ここでは、Qiskitの `QuantumKernel` 概念に基づいた、回路の重なりを測定するロジックを記述します。

```python
from qiskit_algorithms.state_spaces import QuantumKernel
from qiskit_machine_learning.kernels import FidelityQuantumKernel
from qiskit_algorithms.utils import algorithm_globals
from qiskit import Aer
from qiskit.primitives import Sampler

# 乱数シードの固定
algorithm_globals.random_seed = 42

def compute_kernel_matrix(data_list, num_qubits):
    """
    データリストに対してカーネル行列を計算する
    """
    sampler = Sampler()
    
    # ZZFeatureMapを使用（Qiskit標準ライブラリを利用）
    feature_map = ZZFeatureMap(feature_dimension=num_qubits, reps=1)
    
    # FidelityQuantumKernelの構築
    kernel = FidelityQuantumKernel(feature_map=feature_map, sampler=sampler)
    
    # カーネル行列の計算
    kernel_matrix = kernel.evaluate(x=data_list, y=data_list)
    return kernel_matrix

# 計算対象のデータセット
data_set = [
    [0.1, 0.2],
    [0.5, 0.6],
    [0.9, 0.8],
    [0.2, 0.9]
]

kernel_matrix = compute_kernel_matrix(data_set, 2)

print("Computed Kernel Matrix:")
print(kernel_matrix)
```

=== 結果の解析 ===
実行結果として得られるのは、対称行列（$K_{ij} = K_{ji}$）であり、対角成分はすべて1（自分自身との重なりは最大）となります。

出力例（シミュレーション値）:
```text
[[1.         0.8523...  0.6122...  0.7231...]
 [0.8523...  1.         0.5432...  0.5988...]
 [0.6122...  0.5432...  1.         0.4211...]
 [0.7231...  0.5988...  0.4211...  1.        ]]
```

この行列の各要素は、データ $x_i$ と $x_j$ が量子空間においてどれだけ「近い」かを示しています。数値が1に近いほど、量子回路によって生成された状態が似ていることを意味します。

=== まとめ ===
本記事では、PythonとQiskitを用いて、量子カーネル法の核となる「量子特徴写像」と「カーネル行列の計算」を実装しました。
