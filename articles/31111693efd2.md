## 導入：量子回路をエージェントの脳として扱う

強化学習（Reinforcement Learning）は、エージェントが環境との相互作用を通じて、報酬を最大化するための行動方策を学習する手法です。近年、この強化学ティングの「方策（Policy）」の部分に量子回路を組み込む「量子強化学習（QRL）」の研究が進んでいます。

量子回路は、古典的なニューラルネットワークとは異なる、量子的な状態の重ね合わせやもつれを利用した高次元な特徴量表現（量子特徴空間）を持つことが期待されています。本記事では、Qiskitを用いて、量子回路を用いた方策勾配法（Policy Gradient）の基礎的な実装プロセスを解説します分。

## 量子方策勾配法の仕組み

古典的な方策勾配法では、方策パラメータ $\theta$ を更新するために、期待報酬の勾配 $\nabla_{\theta} J(\theta)$ を推定します。量子強化学習においては、この $\theta$ が量子回路の回転ゲート（$RY$ ゲートなど）の角度に対応します。

1. **状態のエンコーディング**: 環境から得られた状態 $s$ を、量子ビットの回転角などのパラメータに変換し、量子状態 $|\psi(s, \theta)\rangle$ を作成します。
2. **行動のサンプリング**: 量子回路の測定結果（ビット列）を、エージェントの行動 $a$ として抽出します。
3. **報酬の獲得**: 行動 $a$ を環境に適用し、報酬 $r$ を得ます。
4. **パラメータ更新**: 報酬に基づき、勾配推定アルゴリズム（Parameter Shift Ruleなど）を用いて、量子回路のパラメータ $\theta$ を更新します。

## 実装：Qiskitを用いた量子方策の構築

以下に、シンプルな量子回路を用いた方策の実装例を示します。ここでは、量子ゲートのパラメータを学習可能な変数として扱います。

```python
import numpy as np
from qiskit import QuantumCircuit
from qiskit.circuit import Parameter

class QuantumPolicy:
    def __init__(self, num_qubits):
        self.num_qubits = num_qubits
        # 学習対象のパラメータ（回転角）
        self.theta = [Parameter(f'θ_{i}') for i in range(num_qubits)]
        self.circuit = self._build_circuit()

    def _build_circuit(self):
        qc = QuantumCircuit(self.num_qubits)
        # 状態エンコーディングと方策層の簡易的な構成
        for i in range(self.num_qubits):
            qc.ry(self.theta[i], i)
        # 量子もつれ（Entanglement）の導入
        for i in range(self.arg_range(self.num_qubits - 1)):
            qc.cx(i, i + 1)
        qc.measure_all()
        return qc

    def arg_range(self, n):
        return range(n)

    def get_action(self, classical_state, params_values):
        """
        量子回路のパラメータに具体的な値を代入し、測定結果（行動）を得る
        """
        executable_circuit = self.circuit.assign_parameters(
            dict(zip(self.theta, params_values))
        )
        # 実際の実行（シミュレータを使用）
        # ここでは簡略化のため、測定結果のビット列を数値として返す
        # 実際の実装では Qiskit Runtime 等を用いて実行する
        return executable_circuit

# パラメータの初期化
num_qubits = 2
policy = QuantumPolicy(num_qubits)
current_params = np.random.uniform(0, 2 * np.pi, num_qubits)

print("Quantum Circuit Structure:")
print(policy.circuit.draw())
```

## パラメータ更新のプロセス（Parameter Shift Rule）

量子回路のパラメータ $\theta$ の勾配を計算する場合、Backpropagation（誤差逆伝播法）を直接適用することは困難です。代わりに、量子回路の特性を利用した「Parameter Shift Rule」を用います。

これは、パラメータを $\theta + \pi/2$ と $\theta - \pi/2$ にずらして2回回路を実行し、その測定結果の差分から勾配を計算する手法です。

$$ \nabla_{\theta} f(\theta) \approx \frac{f(\theta + \frac{\pi}{2}) - f(\theta - \frac{\pi}{2})}{2} $$

この手法を用いることで、量子デバイス上でも正確な勾配計算が可能になります。

## 実装のポイントと課題

量子強化学習を実装する際に直面する主な課題は、以下の2点です。

1. **情報のボトルネック**: 古典的な環境（例：CartPole）の状態情報を、いかに効率的に量子状態へとエンコード（Encoding）するか。単純な回転角への割り当てでは、高次元な状態表現を捉えきれない場合があります。
2. **サンプリングノイズ**: 量子回路の測定は確率的であるため、報酬の勾配を正確に推定するためには、膨大な試行回数（Shot数）が必要となります。
