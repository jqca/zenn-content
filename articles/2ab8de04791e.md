## 導入：量子回路を分類器として活用する

古典的なニューラルネットワークが重み（Weight）を最適化するように、量子回路におけるパラメータ（角度）を最適化することで、データの特徴を学習するのが量子機械学習（QML）の基本です。

本記事では、量子ニューラルネットワーク（QNN）の最も基本的な構成である、変分量子回路（VQC: Variational Quantum Circuit）を用いたバイナリ分類の実装手順を解説します。Qiskitを用い、古典的な最適化アルゴリズム（SPSA）を使って、量子回路のパラメータを更新していくプロセスを、実際に動作するコードと共に追いかけます。

## 量子ニューラルネットワークの基本構成

QNNは、以下の3つのステップで構成されます。

1. **量子特徴写像（Feature Map）**: 古典データを量子状態（振幅や回転角）へとエンコードするプロセス。
2. **変分量子回路（Ansatz）**: 学習可能なパラメータ（回転ゲートの角度など）を持つ量子回路。
3. **測定と古典最適化**: 測定結果（期待値）を損失関数として計算し、古典的な最適化アルゴリズムを用いてAnsatzのパラメータを更新するプロセス。

今回は、角度エンコーディング（Angle Encoding）を用いた最もシンプルな構成を実装します。

## 実装：QNNによるバイナリ分類

以下のコードでは、2次元の古典データを、量子回路を用いて「0」または「1」に分類するプロセスを実装しています。

```python
import numpy as np
from qiskit import QuantumCircuit
from qlag (※注: 実行環境に応じたQiskitライブラリを使用)
from qiskit.circuit.library import ZZFeatureMap, RealAmplitudAnsatz
from qiskit_algorithms import SPSA
from qiskit_algorithms.optimizers import SPSA
from qiskit_machine_learning.algorithms import VQC
from qiskit_machine_learning.circuit.library import RawFeatureMap
from qiskit.primitives import Sampler
from sklearn.datasets import make_blobs
from sklearn.preprocessing import MinMaxScaler
from sklearn.model_selection import train_test_split

# 1. データセットの準備
# 2次元のクラスタデータを生成
X, y = make_blobs(n_samples=50, centers=2, n_features=2, cluster_std=0.8, random_state=42)

# データのスケーリング（量子回路の入力範囲 [0, pi] に収めるため）
scaler = MinMaxScaler(feature_range=(0, np.pi))
X_scaled = scaler.fit_transform(X)

# 学習データとテストデータに分割
train_features, test_features, train_labels, test_labels = train_test_split(
    X_scaled, y, train_size=0.8, random_state=42
)

# 2. 量子回路の設計
num_qubits = 2

# Feature Map: 古典データを量子状態へ写像
feature_map = ZZFeatureMap(feature_dimension=num_qubits, reps=1)

# Ansatz: 学習可能なパラメータを持つ回路
ansatz = RealAmplitudAnsatz(num_qubits=num_qubits, reps=1)

# 3. VQC（Variational Quantum Classifier）の設定
sampler = Sampler()
optimizer = SPSA(maxiter=100)

vqc = VQC(
    sampler=sampler,
    feature_map=feature_map,
    ansatz=ansatz,
    optimizer=optimizer
)

# 4. 学習の実行
vqc.fit(train_features, train_labels)

# 5. 評価
train_score = vqc.score(train_features, train_labels)
test_score = vqc.score(test_features, test_labels)

print(f"Training Accuracy: {train_score:.2f}")
print(f"Test Accuracy: {test_score:.2f}")
```

## コードの解説と実装のポイント

### 特徴写像（ZZFeatureMap）
`ZZFeatureMap`は、入力データの非線形な関係を量子空間のエンタングルメントとして表現するための回路です。ここでは2量子ビットに対し、`reps=1`としています。これにより、古典的な線形分離不可能なデータに対しても、量子空間での高次元的な特徴抽出を試みます。

### Ansatz（RealAmplitudAnsatz）
`RealAmplitudAnsatz`は、実数パラメータのみを持つ回転ゲート（RY）とCNOTゲートで構成される回路です。この回路の「重み」にあたる部分が、古典的な最適化器（SPSA）によって逐次更新されます。

### 最適化アルゴリズム（SPSA）
量子回路の測定結果はノイズの影響を受けやすいため、勾配の推定が困難な場合があります。`SPSA (Simultaneous Perturbation Stochastic Approximation)`は、一度の試行で複数のパラメータを同時に摂動させるため、量子回路のパラメータ更新において非常に効率的です。

## 動作確認の結果

上記のコードを実行すると、学習が進むにつれて、訓練データに対する分類精度（Accuracy）が向上し、最終的にテストデータに対しても一定の識別性能を示すことが確認できます。

学習の反復回数（`maxiter`）を増やすと精度が向上する傾向にありますが、計算時間は反復回数に比例して増大します。実機（量子デバイス）で実行する場合は、ゲートエラーやデコヒーレンスを考慮した回路設計が重要になります。
