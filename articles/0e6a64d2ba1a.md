量子コンピュータのアルゴリズムを設計する際、最初の一歩は「計算の土台となる量子状態を正しく作ること」です。量子計算は、初期状態（通常はすべての量子ビットが $|0\rangle$ の状態）に対してゲート操作を施し、目的の量子状態へと変容させていくプロセスです。

本記事では、PythonとQiskitを用い、単一量子ビットから複数量子ビットへと、特定の量子状態を構築する実装方法を解説します。

## 量子状態の基本：純粋状態と密度行列

量子状態は、ベクトル形式の「状態ベクトル」として表現されることもあれば、観測に伴う不確mathcalな要素（混合状態）を含む「密度行列」として表現されることもあります。

実装のステップでは、まずゲート操作によって純粋状態（Pure State）を作り出し、その状態が意図した確率分布を持っているかを計算によって検証します。

## 任意の角度への回転：Ryゲートによる実装

特定の確率分布を持つ量子ビットを作るには、回転ゲート（Rotation gate）を使用します。例えば、$|0\rangle$ 状態から、$|0\rangle$ と $|1\rangle$ が特定の比率で存在する重ね合わせ状態を作るには、Y軸周りの回転を行う `ry` ゲートが有効です。

以下のコードでは、回転角 $\theta$ を指定して、特定の確率分布を持つ状態を生成します。

```python
import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector

def prepare_single_qubit_state(theta):
    """
    theta角の回転を用いた量子状態の準備
    """
    qc = QuantumCircuit(1)
    # Y軸周りの回転ゲートを適用
    qc.ry(theta, 0)
    
    # 状態ベクトルの取得
    state = Statevector.from_instruction(qc)
    return state

# 例：theta = pi/2 (Hadamardゲートと同様の重ね合わせ状態)
theta_val = np.pi / 2
state_vector = prepare_single・qubit_state(theta_val)

print("Statevector:")
print(state_vector.data)
print("\nProbabilities:")
print(state_vector.probabilities_dict())
```

このコードを実行すると、$\theta = \pi/2$ のとき、状態ベクトルは $[0.707, 0.707]$（実質 $1/\sqrt{2}$）となり、各状態が得られる確率は $50\%$ ずつであることが確認できます。

## 2量子ビットへの拡張：制御回転ゲートによる相関の導入

単一量子ビットの操作を拡張し、2つの量子ビット間に特定の相関（制御された状態変化）を持たせる実装を行います。ここでは、1つ目の量子ビットの状態に応じて、2つ目の量子ビットの回転角度を制御する `ry` ゲートの応用例を示します。

```python
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector

def prepare_two_qubit_correlated_state(theta):
    """
    制御Y回転ゲートを用いた2量子ビット状態の準備
    """
    qc = QuantumCircuit(2)
    
    # 1つ目のビットを重ね合わせ状態にする
    qc.h(0)
    
    # 1つ目のビットが |1> のとき、2つ目のビットを theta だけ回転させる
    qc.cry(theta, 0, 1)
    
    state = Statevector.from_instruction(qc)
    return state

# theta = pi/2 の場合
theta_val = np.pi / 2
state_2q = prepare_two_qubit_correlated_state(theta_val)

print("2-qubit Statevector:")
print(state_2q.data)
```

この実装により、制御ビットの状態とターゲットビットの状態が連動した、特定の振幅を持つ状態を生成できます。

## 状態の検証：密度行列への変換

量子アルゴリズムの解析においては、状態ベクトルだけでなく、密度行列（Density Matrix）を確認することが重要です。これは、ノイズや測定による情報の欠落（混合状態）を扱う際の標準的な表現形式です。

Qiskitの `density_matrix` を用いて、作成した状態が意図通りかを確認します。

```python
from qiskit.quantum_info import DensityMatrix

# 密度行列の生成
dm = DensityMatrix(state_2q)

print("Density Matrix (2x2 partial trace or full):")
print(dm.data)
```

密度行列の対角要素は、各基底状態（$|00\rangle, |01\rangle, |10\rangle, |11\rangle$）が観測される確率を表しています。

## まとめ

量子状態の準備は、量子アルゴリズムの「初期条件」を定義する極めて重要なプロセスです。
- `ry` などの回転ゲートを用いて、振幅（確率）を制御する。
- `cry` などの制御ゲートを用いて、量子ビット間の相関を構築する。
- `Statevector` や `DensityMatrix` を用いて、生成された状態の数学的正当性を検証する。

これらの操作を組み合わせることで、より複雑な量子アルゴリズム（量子位相推定や量子振幅増幅など）の実装へと進むことが可能になります。
