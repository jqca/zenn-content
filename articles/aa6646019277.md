量子コンピュータのアルゴリズムにおいて、複数の量子ビット間の相互作用を制御することは、量子計算の核心と言えます。単一量子ビットへの操作（単一ビットゲート）だけでは、量子ビットが独立した状態で計算が進むため、量子計算特 Man の強力な並列性や相関を利用することができません。

そこで必要となるのが、ある量子ビットの状態に応じて、別の量子ビットの状態を変化させる「制御ゲート」です。本記事では、最も基本的かつ重要な制御ゲートであるCNOT（Controlled-NOT）ゲートに焦点を当て、PythonとQiskitを用いて、量子もつれ（Entanglement）を生成するプロセスを実装・解説します。

## CNOTゲートの仕組み

CNOTゲートは、2つの量子ビット（制御ビットと標的ビット）に対して作用するゲートです。

- **制御ビット（Control qubit）**：状態が $|1\rangle$ のときのみ、標的ビットに操作を加える。
- **標的ビット（Target qubit）**：制御ビットの状態に応じて、パウリXゲート（ビット反転）が適用される。

具体的には、入力状態が $|c, t\rangle$（$c$は制御ビット、$t$は標的ビット）であるとき、出力状態は以下のように遷移します。

- $|0, 0\rangle \rightarrow |0, 0\rangle$
- $|0, 1\rangle \rightarrow |0, 1\rangle$
- $|1, 0\rangle \rightarrow |1, 1\rangle$
- $|1, 1\rangle \rightarrow |1, 0\rangle$

このゲートの真価は、制御ビットにアダマール（H）ゲートを適用し、重ね合わせ状態（$\frac{|0\rangle + |1\rangle}{\sqrt{2}}$）を作った後にCNOTを適用したときに現れます。これにより、ビットの状態が個別に決まっていない「量子もつれ」状態、すなわちベル状態（Bell State）を生成できます。

## Qiskitによる実装

それでは、実際にQiskitを用いてベル状態 $|\Phi^+\rangle = \frac{|00\rangle + |11\rangle}{\sqrt{2}}$ を生成するコードを記述します。

```python
from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator
from qiskit.visualization import plot_histogram

# 1. 2量子ビット、2古典ビットを持つ量子回路の初期化
qc = QuantumCircuit(2, 2)

# 2. 制御ビット（q0）にアダマールゲートを適用し、重ね合わせ状態を作る
qc.h(0)

# 3. CNOTゲートの適用：q0を制御ビット、q1を標的ビットとする
qc.cx(0, 1)

# 4. 量子ビットの測定：q0, q1を古典ビットc0, c1に紐付け
qc.measure([0, 1], [0, 1])

# 5. シミュレータの準備
simulator = AerSimulator()

# 6. 回路の実行
job = simulator.run(qc, shots=1024)
result = job.result()

# 7. 結果の取得
counts = result.get_counts(qc)
print(f"測定結果: {counts}")

# 回路の可視化（テキスト形式）
print("\nQuantum Circuit:")
print(ca.draw(output='text'))
```

## 実装の解説と実行結果の解析

### 回路のステップ
1. `qc.h(0)`：量子ビット0にアダマールゲートを適用します。これにより、ビット0は $|0\rangle$ と $|1\rangle$ の等確率な重ね合わせ状態になります。
2. `qc.cx(0, 1)`：CNOTゲートを適用します。ビット0が $|1\rangle$ である成分に対してのみ、ビット1の値を反転させます。この操作により、ビット0とビット1の状態が数学的に強く相関し、片方の状態を測定した瞬間に、もう片方の状態も確定する「もつれ」状態が生まれます。
3. `qc.measure`：量子的な状態を古典的なビット列として取り出します。

### 実行結果の確認
上記のコードをシミュレータで実行すると、以下のような出力が得られます（実行環境によりビット列の順序表記は異なりますが、論理は同一です）。

```text
測定結果: {'00': 512, '11': 520}
```

この結果から、測定されたビット列は `00` または `11` のいずれかであり、`01` や `10` はほぼ観測されないことがわかります。これは、量子回路が意図通りにベル状態を生成し、2つの量子ビットが「もつれ」た状態になったことを実証しています。

## まとめ

CNOTゲートは、単一ビット操作では不可能な「量子ビット間の相関」を生み出すための必須の演算です。このゲートを応用することで、量子テレポーテーションやスーパーデデンキ（Superdense Coding）といった、量子コンピュータ特有の高度なアルゴリズムの構築が可能になります。

量子計算のプログラミングにおいて、ビット間の相互作用をどのように制御するかを理解することは、複雑な量子アルゴリズムを実装する上での第一歩となります。
