量子コンピュータのアルゴリズムを設計する際、特定の確率分布に従って量子状態を生成するプロセスは、量子機械学習や量子サンプリングの根幹をなす非常に重要なステップです。

本記事では、古典的な確率分布を量子ビットの振幅としてエンコードする手法、いわゆる量子シャノン・サンプリング（Quantum Shannon Sampling）の基礎となる、量子状態の準備（State Preparation）に焦点を当てます。具体的には、Qiskitを用いて、与えられた確率分布を量子回路でどのように表現し、その結果を観測（サンプリング）するかを実装レベルで解説します。

## 量子サンプリングの目的と課題

量子サンプリングの目的は、量子回路の実行結果から、特定の確率分布に従うサンプルを得ることにあります。古典的なコンピュータでは、分布の計算量が増大するとサンプリングコストが膨らみますが、量子コンピュータを用いることで、特定の構造を持つ分布に対して効率的なサンプリングが可能になると期待されています。

実装上の最大の課題は、「どのようにして、任意の確率分布を量子ビットの振幅へと変換するか」という点にあります。これを「アンローディング（Unloading）」や「エンコーディング」と呼びます。

## 実装のステップ：角度を回転させる

ここでは、もっとも基本的なケースとして、2つの状態（0と1）に対して、それぞれ異なる確率 $p_0$ と $p_1$ を割り当てる回路を考えます。

1. 確率の計算：$p_0 + p_1 = 1$ となるように設定。
2. 回転角の決定：量子ビットを $|0\rangle$ から $|\psi\rangle = \sqrt{p_0}|0\rangle + \sqrt{p_1}|1\rangle$ へ回転させるための角度 $\theta$ を求める。
   $\cos(\theta/2) = \sqrt{p_0}$
   $\sin(\theta/2) = \sqrt{p_1}$
3. ゲートの適用：$Ry(\theta)$ ゲートを使用して、初期状態 $|0\rangle$ に回転を適用する。

## Pythonによる実装

以下に、Qiskitを用いた実装コードを示します。

```python
import numpy as np
from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator
from qiskit.visualization import plot_histogram

def prepare_quantum_distribution(p0):
    """
    確率 p0 に基づいて、|0> 状態を 
    sqrt(p0)|0> + sqrt(1-p0)|1> へ変換する回路を作成する
    """
    # p1 は自動的に 1 - p0 となる
    p1 = 1 - p0
    
    # 振幅の計算
    # Ryゲートの引数は、|0> 状態を回転させる角度 theta
    # cos(theta/2) = sqrt(p0) を解く
    theta = 2 * np.arccos(np.sqrt(p0))
    
    # 1量子ビットの回路を作成
    qc = QuantumCircuit(1)
    qc.ry(theta, 0)
    
    return qc

# 1. パラメータの設定
target_p0 = 0.3  # 0が出る確率を30%に設定

# 2. 回路の生成
circuit = prepare_quantum_distribution(target_p0)

# 3. シミュレータの実行
simulator = AerSimulator()
# 測定用の回路を作成
qc_with_measure = circuit.copy()
qc_with_measure.measure_all()

# 試行回数
shots = 1024

# 実行
job = simulator.run(qc_with_measure, shots=shots)
result = job.result()
counts = result.get_counts()

# 4. 結果の表示
print(f"Target p0: {target_p0}")
print(f"Measured counts: {counts}")
```

## 実行結果の検証

上記のコードを実行すると、出力される `counts`（測定された0と1の回数）の比率は、設定した `target_p0` に近似します。

例えば、`target_p0 = 0.3` で `shots = 1024` の場合、出力は概ね以下のようになります。
`{'0': 312, '1': 712}`

このとき、実測の比率は $312 / 1024 \approx 0.304$ となり、設定値に近い結果が得られていることがわかります。

## 多値分布への拡張（考え方）

今回は1量子ビット（2つの状態）を扱いましたが、$n$ 個の事象を持つ分布を扱う場合は、 $n$ 量子ビットを使用します。この場合、単純な $Ry$ ゲートの回転だけでなく、複数のゲートを組み合わせた「角度エンコーディング」が必要になります。

実装の複雑度は増しますが、基本的には以下のプロセスを繰り返します。
1. 各状態の確率 $p_i$ を特定する。
2. 角度 $\theta$ を、各確率の平方根に基づいた回転角として計算する。
3. $R_y$ ゲートや、多量子ビットに対する制御 $R_y$ ゲートを用いて、振幅を逐次的に割り当てる。

より高度な実装では、量子回路の深さを抑えるために、決定木（Decision Tree）の構造を利用した実装手法も存在します。
