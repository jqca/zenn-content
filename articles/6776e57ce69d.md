## 導入：量子特徴写像によるカーネル法の実装

機械学習におけるカーネル法は、低次元のデータを高次元の再生核ヒルベルト空間（RKHS）へ写像することで、線形分離不可能なデータに対して線形分類器を適用可能にする手法です。量子コンピュータはこの「高次元空間への写像」を、量子状態の構築（量子特徴写向）として自然に実行できる可能性を持っています。

本記事では、PythonとQiskitを用い、古典的なSVM（Support Vector Machine）のカーネル関数を量子回路に置き換えた「量子カーネル法」の実装手順を解説します。

## 量子カーネル法の仕組み

量子カーネル法では、以下のプロセスで計算を行います。

1. **量子特徴写像 (Quantum Feature Map)**: 入力データ $x$ を、量子ゲートのパラメータとして量子状態 $|\phi(x)\rangle$ に変換します。
2. **量子カーネル計算**: 2つのデータ $x_i, x_j$ に対するカーネル値（類似度）を、量子回路の出力（期待値）として計算します。
   $K(x_i, x_j) = |\langle\phi(x_i)|\phi(x_j)\rangle|^2$
3. **古典的な学習**: 計算されたカーネル行列を、古典的なSVMアルゴリズムに入力して境界を決定します。

## 実装：量子カーネルを用いた分類器

以下に、Qiskitを用いて、Z-FeatureMapを使用した量子カーネル計算と、scikit-learnによる分類の実装を示します。

```python
import numpy as np
from qiskit.circuit.library import ZFeatureMap
from qiskint_machine_learning.kernels import TrainableFidelityQuantumKernel
from qiskit_algorithms.utils import algorithm_globals
from qiskit_machine_learning.algorithms import QSVC
from sklearn.svm import SVC
from sklearn.datasets import make_blobs
from sklearn.preprocessing import MinMaxScaler

# 乱数シードの固定
algorithm_globals.random_seed = 42

# 1. データセットの準備
# 2次元のデータを生成し、量子回路に入力可能な範囲に正規化
X, y = make_blobs(n_samples=20, centers=2, n_features=2, cluster_std=0.8, random_state=42)
scaler = MinMaxScaler(feature_range=(0, np.pi))
X_scaled = scaler.fit_transform(X)

# 2. 量子回路（Feature Map）の定義
# 特徴量の次元数に合わせて量子ビット数を設定
num_features = X_scaled.shape[1]
feature_map = ZFeatureMap(feature_dimension=num_features, reps=2)

# 3. 量子カーネルの構築
# FidelityQuantumKernelを用いて、量子状態の重なりを計算する
# ここでは、量子計算のコストを考慮し、計算可能な範囲の量子ビット数を使用
q_kernel = TrainableFidelityQuantumKernel(feature_map=feature_map)

# 4. 量子サポートベクター分類器 (QSVC) の実装
# 古典的なSVCに量子カーネルを適用する
qsvc = QSVC(quantum_kernel=q_kernel)

# 5. 学習と予測
# 訓練データを用いて学習
qsvc.fit(X_scaled, y)

# テストデータ（ここでは訓練データと同じを使用）の予測
predictions = qsvc.predict(X_scaled)

# 結果の評価（簡易的な一致確認）
accuracy = np.mean(predictions == y)
print(f"Accuracy: {accuracy * 100:.1f}%")
```

## コードの解説

### 特徴写像（ZFeatureMap）
`ZFeatureMap` は、入力データを量子ゲートの回転角にエンコードします。$Z$ ゲートの回転を繰り返すことで、古典的な手法では表現が困難な複雑な非線形写像を量子空間上に構築します。`reps` 引数を増やすことで、より複雑な量子状態を作成できますが、回路の深さ（実行時間）が増大します。

### 量子カーネルの計算
`TrainableFidelityQuantumKernel` は、量子回路の出力（Fidelity）をカーネル値として抽出します。具体的には、2つのデータに対応する回路を実行し、その量子状態の重なり（Overlap）を測定しています。

## 実行時の注意点

量子カーネル法は、量子ビット数や `reps` の増加に伴い、カーネル行列の計算量が指数関数的に増大します。
- **計算量**: カーネル行列のサイズは $N \times N$ （$N$ はサンプル数）です。全要素の計算には $N(N-1)/2$ 回の量子回路実行が必要です。
- **精度**: 量子ノイズの影響を考慮する場合、ショット数（測定回数）が不足するとカーネル値の分散が大きくなり、分類精度に影響を与えます。

AI×量子の研究において、量子カーネル法は「量子的な特徴抽出」の基礎となる重要な手法です。
