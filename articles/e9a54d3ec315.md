## 導入：量子古典ハイブリッド学習の仕組み

量子コンピュータの計算能力を現在のNISQ（Noisy Intermediate-Scale Quantum）デバイスで引き出すための中心的な手法が、量子古典ハイブリッド学習です。この手法では、量子回路（Parametrized Quantum Circuit: PQC）を「モデル」として使い、そのパラメータを古典的な最適化アルゴリズムで更新していきます。

具体的には、以下のループを繰り返します。
1. 量子デバイス（またはシミュレータ）にパラメータを投入し、回路を実行する。
2. 測定結果から期待値（損失関数に相当する値）を算出する。
3. 古典コンピュータ上で、損失関数を最小化するようにパラメータを更新する。

本記事では、Qiskitを用いて、量子回路のパラメータを更新し、簡単な分類タスクを解くための実装手順を解説します。

## 実装環境

本記事では、以下の環境で動作を確認しています。
- Python 3.x
- Qiskit 1.x
- 実行デバイス：`qiskit-aer`（量子回路シミュレーラ）

## 量子回路（PQC）の設計と実装

まず、パラメータ化された量子回路を作成します。ここでは、回転ゲート（$R_y$ゲート）の角度を学習対象のパラメータとします。

```python
import numpy as np
from qiskit import QuantumCircuit
from qiskit.circuit import Parameter

# パラメータの定義
theta = Parameter('θ')

# 量子回路の構築
def create_pqc(num_qubits, params):
    qc = QuantumCircuit(num_qubits)
    # 初期状態の準備（例：|0> 状態に回転を適用）
    for i in range(num_qubits):
        qc.ry(params[i], i)
    
    # エンタングルメントの追加（回路の表現力を高める）
    for i in range(num_qubits - 1):
        qc.cx(i, i + 1)
        
    qc.measure_all()
    return qc

num_qubits = 2
pqc = create_pqc(num_qubits, [theta] * num_qubits)
print(pqc.draw())
```

## 実行結果の考察

最適化の結果、パラメータ $\theta$ がターゲットとなる期待値を実現するように更新されることが確認できます。

このプロセスにおいて重要なのは、勾配（Gradient）の計算方法です。量子回路は、古典的な自動微分（Autograd）を直接適用することが難しいため、「Parameter Shift Rule」と呼ばれる手法を用いて、量子回路の実行のみから勾配を推定します。

Parameter Shift Ruleの数式：
$\nabla_{\theta} f(\theta) = \frac{1}{2} (f(\theta + \frac{\pi}{2}) - f(\theta - \frac{\pi}{2}))$

これにより、量子デバイス上での測定結果から、パラメータに対する正確な勾配を計算することが可能になります。
