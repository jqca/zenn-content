## 導入：量子位相推定の役割
量子アルゴリズムの多くは、ユニタリ演算子 $U$ の固有値（または固有値に関連する位相）を特定することから始まります。この「量子位相推定（Quantum Phase Estimation, QPE）」は、量子振幅推定（QAE）や、量子化学計算におけるエネルギー固有値の算出、さらにはHHLアルゴリズムといった量子線形代数アルゴリズムの基盤となる極めて重要な技術です。

本記事では、PythonとQiskitを用い、実際に動作するコードを通じて、どのようにして量子回路がユニタリ演算子の位相 $\theta$ を推定するのか、その実装プロセスを解説します。

## 量子位相推定の仕組み
量子位相推定の目的は、あるユニタリー演算子 $U$ と、その固有状態 $|\psi\rangle$ が与えられたとき、以下の関係を満たす位相 $\theta$ を求めることです。
$$U|\psi\rangle = e^{2\pi i \theta}|\psi\rangle$$

このアルゴリズムは、主に2つのレジスタを使用します。
1. **精度レジスタ（Counting Register）**：推定したい位相 $\theta$ のビット精度を決定するレジスタ。
2. **状態レジスタ（Target Register）**：ユニタリ演算子 $U$ が作用する対象となる状態 $|\psi\rangle$ を保持するレジスタ。

プロセスは大きく分けて以下の3ステップです。
1. **重ね合わせの生成**：精度レジスタにアダマールゲートを適用し、すべての状態の重ね合わせを作ります。
2. **制御ユニタリ演算の適用**：精度レジスタの各ビットに対して、制御演算 $U^{2^j}$ を適用します。これにより、位相の情報が精度レジスタの各ビットへ「エンコード」されます。
3. **逆量子フーリエ変換（IQFT）**：位相がエンコードされた状態を、計算可能なビット形式に戻すために、量子フーリエ変換の逆変換を適用します。

def build_complete_qpe(precision_bits, theta):
    n = precision_bits
    qc = QuantumCircuit(n + 1, n)
    
    # 初期化
    for i in range(n):
        qc.h(i)
    qc.x(n) # ターゲットレジスタを |1> に
    
    # 制御回転演算の適用
    for i in range(n):
        angle = 2 * np.pi * theta * (2**i)
        qc.cp(angle, i, n)
        
    # 逆量子フーリエ変換 (IQFT)
    for i in range(n-1, -1, -1):
        for j in range(i):
            # 制御位相ゲート
            # IQFTの各ステップの回転角を計算
            angle = -np.pi / (2**(i-j))
            qc.cp(angle, j, i)
        qc.h(i)
        
    qc.measure(range(n), range(n))
    return qc

# パラメータ設定
precision_bits = 4
target_theta = 0.125 # 1/8 = 0.001 binary
simulator = AerSimulator()
circuit = build_complete_qpe(precision_bits, target_theta)

# 実行
job = simulator.run(circuit, shots=1024)
result = job.result()
counts = result.get_counts()

print("測定結果 (バイナリ形式):", counts)

## 実行結果の解析
上記のコードを実行すると、測定結果としてバイナリ形式の文字列が出力されます。
例えば、`theta = 0.125`（$2^{-3}$）の場合、4ビットの精度レジスタでは、値は `0100`（$4/16 = 0.25$ ではなく、ビットの並びにより $2^{-3}$ を示す値）として現れます。

出力されるビット列を、$\theta = \text{value} / 2^n$ の計算式に当てはめることで、元の位相を復元できます。

## まとめ
量子位相推定は、量子コンピュータが持つ「周期性を見出す能力」を具体的な数値へと変換する橋渡し役です。このアルゴリズムの精度は、精度レジスタの量子ビット数（$n$）に依存し、ビット数を増やすほど $\theta$ の解像度は高まりますが、回路の深さ（ゲート数）が増大するというトレードオフが存在します。

量子計算の基礎を理解する上で、この「位相を回転としてエンコードし、フーリエ変換でデコードする」という流れを把握しておくことは、量子アルゴリズム実装の強力な武器となります。
