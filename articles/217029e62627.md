## 導入：グラフ構造とAI×量子

グラフデータは、SNSのつながり、分子構造、交通ネットワークなど、現実世界の複雑な関係性を表現するのに非常に強力なデータ形式です。近年、これらを扱う手法としてグラフニューラルネットワーク（GNN）が発展してきましたが、グラフの複雑な特徴をより高次元な空間で捉えるアプローチとして、「AI×量子」の領域における量子グラフニューラルネットワーク（QGNN）が注目されています。

本記事では、Qiskitを用いて、量子回路（パラメータ化量子回路：PQC）をグラフのノード特徴抽出器として組み込む、量子グラフニューラルネットワークの基礎的な実装を解説します。

## グラフデータの表現と量子回路への埋め込み

QGNNの基本構成は、各ノードに量子状態を割り当て、エッジ（接続関係）に基づいたメッセージパッシング（情報の集約）を量子回路で行うものです。

実装のステップは以下の通りです。
1. ノード特徴量（スカラー値など）を量子ビットの状態にエンコードする。
2. 量子回路（PQC）を用いて、ノードの特徴を量子状態の回転として更新する。
3. 隣接ノードの量子状態を、量子演算を通じて集約する。

ここでは、最もシンプルな「量子特徴写像」を用いた実装に焦点を当てます。

## 実装：Qiskitによる量子ノード特徴更新

以下に、ノodeの属性を量子ビットの回転角に変換し、量子回路で特徴を処理する最小構成のコードを示します。

```python
import numpy as np
from qiskit import QuantumCircuit
from qiskit.circuit import Parameter

def create_qgnn_layer(num_nodes, num_qubits, params):
    """
    各ノードの量子回路を生成する
    """
    qc = QuantumCircuit(num_qubits)
    
    # 1. 特徴量のエンコード (Angle Encoding)
    # ノードの属性値を量子ビットの回転に変換
    for i in range(num_nodes):
        if i < num_qubits:
            # 便宜上、ノードのインデックスを回転角として利用
            qc.ry(np.pi * i / num_nodes, i)
            
    # 2. 量子演算（メッセージパッシングの抽象化）
    # パラメータ化された回転ゲートにより、特徴を更新
    for i in range(num_qubits):
        qc.rx(params[i], i)
        qc.rz(params[i + num_qubits], i)
        
    return qc

# 設定
num_nodes = 4
num_qubits = 4
# 実行に必要なパラメータ（回転角）の生成
parameters = [Parameter(f'θ_{i}') for i in range(num_qubits * 2)]

# 量子回路の構築
qgnn_layer = create_qgnint_layer(num_nodes, num_qubits, parameters)

print("Generated QGNN Layer Circuit:")
print(qgnn_layer.decompose().draw())
```

## 量子回路による情報の集約（Aggregation）

実際のGNNでは、隣接ノードから情報を集める「集約」が不可欠です。量子回路においては、CNOTゲートなどの多量子ビットゲートを用いて、隣接するノード（量子ビット）間の相関（Entanglement）を作ることで、情報の集約をシミュレートできます。

```python
def apply_aggregation(qc, num_qubits, adjacency_matrix):
    """
    隣接行列に基づき、CNOTゲートで量子ビット間の相関（集約）を作成する
    """
    for i in range(num_qubits):
        for j in range(num_qubits):
            if i != j and adjacency_matrix[i][j] > 0:
                # エッジが存在する場合、CNOTで情報を伝播
                qc.cx(i, j)
    return qc

# 隣接行列の定義（例：線形グラフ）
adj_matrix = [
    [0, 1, 0, 0],
    [1, 0, 1, 0],
    [0, 1, 0, 1],
    [0, 0, 1, 0]
]

# 既存の回路に集約プロセスを追加
qgnn_layer_with_agg = apply_aggregation(qgnn_layer.copy(), num_qubits, adj_matrix)

print("\nQGNN Layer with Aggregation (Entanglement):")
print(qgnn_layer_with_agg.decompose().draw())
```

## 実行と期待値の測定

学習可能なパラメータ $\theta$ を最適化するためには、回路の出力から「期待値」を取り出す必要があります。ここでは、各量子ビットの $Z$ 測定の期待値を計算することで、ノードの新しい特徴量を算出します。

```python
from qiskit_algorithms import SamplingTerm
from qiskiment_aer import AerSimulator
from qiskit.primitives import Estimator

# シミュレータの準備
estimator = Estimator()

# 測定対象のオブザーバブル（Z演算子）
observables = [
    QuantumCircuit(num_qubits).z(i) for i in range(num_qubits)
]

# テスト用のパラメータ値（最適化の過程で更新される値）
input_params = [0.5] * len(parameters)

# 期待値の計算
# 注: 実際の学習では、loss functionを定義して勾配降下法を用いる
def compute_node_features(circuit, params_values, observables):
    # 実行用のパラメータ割り当て
    bound_circuit = circuit.assign_parameters(params_values)
    
    results = []
    for obs in observables:
        # 各ノードの特徴量として、各ビットの期待値を取得
        job = estimator.run(bound_circuit, obs)
        results.append(job.result().values[0])
    return results

node_features = compute_node_features(qgnn_layer_with_agg, input_params, observables)
print("\nUpdated Node Features (Expectation Values):")
print(node_features)
```

## 考察：量子グラフ学習の可能性

この実装で示した手法は、量子回路を「学習可能なフィルタ」として機能させるものです。
従来のGNNでは、重み行列の計算に多大な計算資源を要しますが、QGNNでは量子ビット間のエンタングルメントを利用することで、高次元な特徴空間における非線形な特徴抽出を、量子回路のパラメータ更新という形で実現できます。

ただし、現在のNISQ（Noisy Intermediate-Scale Quantum）デバイスにおいては、量子ビット数とゲートの深さに制約があるため、巨大なグラフをそのまま扱うことは困難です。今後は、グラフのサブグラフ抽出（Graph Partitioning）と量子回路のサイズを適合させる手法が、実用的な実装の鍵となります。

量子コンピュータの計算資源を、グラフ構造の複雑なパターン認識に活用する研究は、材料科学の分子解析や、複雑なネットワークの異常検知など、広範な分野への応用が期待されています。
