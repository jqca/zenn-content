=== 導入 ===
量子コンピュータのアルゴリズムを設計する際、特定の条件を満たす状態の確率（振幅）を、いかに効率的に、かつ高精度に測定できるかは極めて重要な課題です。

通常の量子測定では、観測結果から得られるのは「どの状態が得られたか」というサンプルのみであり、その出現確率を正確に推定するには、膨大な回数の試行（サンプリング）が必要です。この試行回数は、求めたい精度に対して反比例（$1/\epsilon^2$）で増加するため、精度を上げようとすると計算コストが爆発的に増大します。

量子振幅推定（Quantum Amplitude Estimation: QAE）は、この課題に対し、量子アルゴリズムを用いることで、試行回数の依存度を精度に対して反比例（$1/\epsilon$）へと改善する手法です。本記事では、Qiskitを用いて、量子振幅推定の基礎となる仕組みと、実際に動作するコードの実装方法を解説します。

=== 量子振幅推定の原理 ===
量子振幅推定の核心は、アルゴリズムの目的とする「状態の確率」を、ユニタリ演算子の「位相」へと変換することにあります。

具体的には、以下のステップを踏みます。

1. 準備状態の構成：
ターゲットとなる状態（解となる状態）の確率 $a$ を持つ量子状態を、角度 $\theta$ を用いて $\sin(\theta) = \sqrt{a}$ となるように構成します。

2. 振幅増幅（Grover演算子）の適用：
Groverのアルゴリズムの基本要素である「拡散演算子」を繰り返し適用します。これにより、ターゲット状態の振幅が回転（回転角 $2\theta$）していきます。

3. 位相推定の適用：
回転した角度 $\theta$ を、量子位相推定（QPE）を用いて抽出します。この $\theta$ から、元の確率 $a = \sin^2(\theta)$ を逆算します。

このプロセスにより、古典的なサンプリングでは不可能であった、高精度な確率推定が可能になります。

=== 実装：Qiskitによる量子振幅推定の構成 ===
ここでは、最も簡略化された形式の、量子振幅推定のコア部分を実装します。ターゲットとなる確率 $a$ を、量子ゲートによって制御可能な形に持ち込み、それを推定する流れを追います。

```python
import numpy as np
from qiskit import QuantumCircuit
from qiskity_algorithms import AmplitudeEstimation, EstimationProblem
from qiskit_aer import AerSimulator

def create_amplitude_estimation_circuit(theta):
    """
    角度thetaに基づいた量子状態を準備する回路
    """
    # 1量子ビットの回路
    qc = QuantumCircuit(1)
    # thetaの回転を実現
    qc.ry(2 * theta, 0)
    return qc

def run_qae_example(target_probability):
    """
    量子振幅推定を実行する
    """
    # 1. ターゲットとなる確率から角度thetaを計算
    # sin(theta) = sqrt(target_probability)
    theta = np.arcsin(np.sqrt(target_probability))
    
    # 2. 準備状態の回路を作成
    qc = create_amplitude_estimation_circuit(theta)
    
    # 3. EstimationProblemの構築
    # ここでは、作成した回路が「ターゲット状態」を指すように設定
    # 本来は、より複雑な、状態の準備とOracleの構成が必要
    problem = EstimationProblem(
        state=qc,
        a=target_probability # 目標とする確率
    )
    
    # 4. 振幅推定器（AE）の初期化
    # AerSimulatorを使用してシミュレーション
    ae = AmplitudeEstimation(sampler=AerSimulator())
    
    # 5. 実行
    result = ae.estimate(problem)
    
    return result.estimation, result.confidence_interval

# --- 実装の検証 ---
# 実測するターゲット確率
target_a = 0.3
est_val, confidence = run_qae_example(target_a)

print(f"Target Probability: {target_a}")
print(f"Estimated Probability: {est_val}")
print(f"Confidence Interval: {confidence}")
```

=== コードの解説 ===
この実装において重要なのは、`EstimationProblem` と `AmplitudeEstimation` の役割分担です。

- `EstimationProblem`: 
量子回路（`state`）と、私たちが推定したい確率の理論値（`a`）を定義します。ここでは、`ry` ゲートを用いて、特定の角度 $\theta$ を持つ量子状態を生成しています。

- `AmplitudeEstimation`: 
このクラスが、内部的に Grover 演算子（Grover Operator）を構築し、量子位相推定（QPE）のロジックを適用して、$\theta$ を抽出します。

- `AerSimulator`: 
量子回路の実行をシミュレーションします。実際の量子デバイスでは、ノイズの影響により推定精度が低下しますが、シミュレーション上では理論値に近い結果が得られます。

=== 計算量の比較 ===
なぜ量子振幅推定を用いる必要があるのか、その理由は計算量の違いにあります。

- 古典的サンプリング（Monte Carlo法）:
精度 $\epsilon$ を得るために必要な試行回数は $O(1/\epsilon^2)$ です。

- 量子振幅推定:
精度 $\epsilon$ を得るために必要な量子操作の回数は $O(1/\epsilon)$ です。

例えば、精度を $1/10$ から $1/100$ に向上させたい場合、古典的手法では試行回数を 100 倍にする必要がありますが、量子振幅推定では 10 倍の計算量で済む計算になります。これが、量子アルゴリズムが大規模な確率計算において優位性を持つ理由の一つです。
