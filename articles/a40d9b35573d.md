量子コンピュータのアルゴップリズムの中でも、特に量子振幅推定（QAE）の基盤となるのが「量子位相推定（Quantum Phase Estimation: QPE）」です。量子振幅推定は、ユニタリ演算子の期待値を量子回路で直接読み取る手法ですが、その背後で「演算子の固有値（位相）」を特定しているのがこのQPEです。

本記事では、Qiskitを用いて、与えなるユニタリ演算子の固有値（位相）を、量子回路の実行結果からどのように抽出するか、その実装プロセスを解説します。

## 量子位相推定の原理

ユニタリ演算子 $U$ が固有値 $e^{2\pi i \theta}$ を持つ固有状態 $|\psi\rangle$ を持つとき、この $\theta$ （位相）を推定することがQPEの目的です。

回路構成は大きく分けて以下の要素で構成されます。
1. **精度を決定する補助量子ビット（ancilla qubits）**: 位相のビット精度を決定します。ビット数が多いほど、推定精度が高まります。
2. **制御ユニタリゲート（Controlled-U）**: 補助量子ビットに対して、 $U$ の累乗を段階的に適用します。
3. **逆量子フーリエ変換（Inverse Quantum Fourier Transform: IQFT）**: 振幅の形（周波数成分）として表現されている位相情報を、ビット形式の数値に変換します。

## Qiskitによる実装

今回は、最も基本的な「位相 $\theta = 1/4$」を持つ演算子をターゲットに、2ビットの補助量子ビットを用いて推定を行うコードを書きます。

```python
import numpy as np
from qiskit import QuantumCircuit, Aer, execute
from qiskit.circuit.library import QFT

def create_qpe_circuit(n_ancilla, target_qubits):
    """
    n_ancilla: 精度を決める補助量子ビット数
    target_qubits: 演算子を適用する対象量子ビット数
    """
    # 補助量子ビット + ターゲット量子ビットの合計数
    total_qubits = n_ancilla + target_qubits
    qc = QuantumCircuit(total_qubits, n_ancilla)

    # 1. 補助量子ビットを重ね合わせ状態にする
    for i in range(n_ancilla):
        qc.h(i)

    # 2. ターゲット量子ビットを初期状態 |1> に設定（位相を検出するため）
    for i in range(n_ancilla, total_qubits):
        qc.x(i)

    # 3. 制御ユニタリ演算の適用
    # 今回は簡易的に、位相回転ゲート(PhaseGate)を制御ゲートとして使用
    # theta = 0.25 (1/4) を抽出することを目標とする
    phase = 0.25
    for i in range(n_ancilla):
        # 制御ビット i に対して、U^(2^i) を適用
        # 2^i の重みに応じて回転角を調整
        angle = 2 * np.pi * phase * (2**i)
        qc.cp(angle, i, n_ancilla)

    # 4. 逆量子フーリエ変換 (IQFT) の適用
    # 補助量子ビット部分に対してのみIQFTを適用
    qc.append(QFT(n_ancilla).inverse(), list(range(n_ancilla)))

    # 5. 測定
    qc.measure(range(n_ancilla), range(n_ancilla))
    
    return qc

# 設定
n_ancilla = 2
n_target = 1

# 回路生成
qc = create_qpe_circuit(n_ancilla, n_target)

# 実行
backend = Aer.get_backend('qasm_simulator')
job = execute(qc, backend, shots=1024)
counts = job.result().get_counts()

print("測定結果 (bitstring: counts):")
print(counts)
```

## 実装のポイントと動作解説

### ターゲット状態の準備
QPEで位相を検出するためには、演算子 $U$ が作用する状態を適切に準備する必要があります。上記のコードでは、ターゲットビットを `qc.x(i)` で $|1\rangle$ 状態にしています。これは、位相回転ゲート $R_z(\theta)$ が $|1\rangle$ に対してのみ位相変化をもたらす性質を利用しているためです。

### 制御演算のスケール
QPEの肝は、補助ビットの $k$ 番目のビットに対して、$U^{2^k}$ を適用することです。これにより、位相の各ビット（$2^{-1}, 2^{-2}, \dots$）が、補助量子ビットの振幅としてエンコードされます。コード内の `angle = 2 * np.pi * phase * (2**i)` は、このスケーリングを表現しています。

### 逆量子フーリエ変換の役割
制御演算が終わった段階では、位相情報は「量子フーリエ変換された状態」として、各量子ビットの位相差に分散しています。これを、私たちが読み取れる「ビット値（$0$ か $1$ か）」に変換するために、IQFTが必要です。

## 実測結果の解釈

上記のコードを実行すると、以下のような出力が得られます（実行環境によりビットの順序は前後しますが、数値の意図は同じです）。

```text
測定結果 (bitstring: counts):
'01': 512
'00': 512
```

ここで、ターゲットとした位相は $\theta = 0.25$ です。
2進数表記で $0.25$ は $0.01_2$ となります。
出力されたビット列 `01`（Qiskitのビット順序に基づき、下位ビットから順に解釈）が、正しく $2^{-2}$ の位置に $1$ が立っていることを示しています。

もし `n_ancilla` を増やして（例：3ビットや4ビット）、より細かい位相（例：$\theta = 0.125$）をターゲットにした場合、測定結果の分布はさらに特定のビット列に収束していく様子が確認できます。

## まとめ

量子位相推定は、量子アルゴリズムの「中核的な部品」です。
- 補助量子ビットが、位相の各桁（重み）を保持する。
- 制御 $U$ ゲートによって、位相が量子状態の振幅にエンコードされる。
- IQFTによって、振幅情報からビット情報へ変換する。

このプロセスを理解することは、量子振幅推定や、より複雑な量子化学シミュレーションのアルゴリズムを実装する際の強力な基礎となります。
