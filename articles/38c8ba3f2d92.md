量子コンピュータの真価を発揮するアルゴリズムの多くは、ハミルトニアンの固有値（エネルギー）を求めることに依存しています。その中核を担うのが「量子位相推定（Quantum Phase Estimation: QPE）」です。

本記事では、Qiskitを用いて量子位相推定を実装し、制御ユニタリ演算からどのようにして位相（固有値）が抽出されるのか、そのプロセスをコードと共に解説します。

## 量子位相推定の目的

量子位相推定の目的は、あるユニタリ演算 $U$ と、その固有状態 $|\psi\rangle$ が与えられたとき、以下の関係式を満たす位相 $\theta$ を求めることです。

$$U|\psi\rangle = e^{2\pi i \theta}|\psi\rangle$$

この $\theta$ は $0 \le \theta < 1$ の範囲にあります。この手法が重要視されるのは、量子化学計算における分子の基底状態エネルギーの推定や、ショアのアルゴリズムにおける周期発見のステップにおいて、この位相の特定が計算の根幹となるためです。

## アルゴリズムの構成要素

量子位相推定は、大きく分けて以下の2つのレジスタを使用します。

1. **精度決定レジスタ（Ancilla qubits）**: 求めたい位相 $\theta$ の精度（ビット数）を決定するレジスタです。
2. **状態レジスタ（Target qubits）**: 演算 $U$ が作用する、固有状態 $|\psi\rangle$ を保持するレジスタです。

アルゴリズムのフローは以下の通りです。
1. 精度決定レジスタを重ね合わせ状態にする（アダマールゲートの適用）。
2. 制御ユニタリ演算（Controlled-$U^{2^j}$）を、精度決定レジスタの各ビットに対して適用する。これにより、位相の情報が精度決定レジスタの位相差としてエンコードされます。
3. 逆量子フーリエ変換（Inverse Quantum Fourier Transform: IQFT）を精度決定レstraに適用し、位相をビット列に変換する。
4. 精度決定レジスタを測定する。

## Qiskitによる実装

ここでは、最も単純なケースとして、ターゲットとなる演算 $U$ を $R_z$ ゲート（回転ゲート）とし、その回転角から位相を推定する実装を行います。

```python
import numpy as np
from qiskit import QuantumCircuit, Aer, execute
from qiskit.circuit.library import QFT

def quantum_phase_estimation(n_precision, theta):
    """
    n_precision: 精度決定レジスタの量子ビット数
    theta: 抽出したい位相 (0 <= theta < 1)
    """
    # 精度決定レジスタ (n_precision) + ターゲットレジスタ (1)
    qc = QuantumCircuit(n_precision + 1, n_precision)

    # 1. 精度決定レジスタの初期化 (Hadamard gate)
    for i in range(n_precision):
        qc.h(i)

    # 2. ターゲットレジスタの初期化 (|1>状態にする)
    qc.x(n_precision)

    # 3. 制御ユニタリ演算の適用
    # U = Rz(2 * pi * theta) に相当する制御回転ゲートを適用
    # 精度決定レジケートの各ビットに対して、2^j 倍の回転を適用する
    for i in range(n_precision):
        # 角度の計算: 2 * pi * theta * 2^i
        angle = 2 * np.pi * theta * (2**i)
        # 制御回転ゲート (cp) を使用
        # 実際の実装では、位相をエンコードするために 2^j 倍の回転が必要
        qc.cp(angle, i, n_precision)

    # 4. 逆量子フーリエ変換 (IQFT) の適用
    # QFTの逆変換を行うことで、位相情報をビット列に戻す
    qc.append(QFT(n_precision).inverse(), list(range(n_precision)))

    # 5. 測定
    for i in range(n_precision):
        qc.measure(i, i)
    
    return qc

# パラメータ設定
n_bits = 4  # 精度決定レジスタのビット数
target_theta = 0.125  # 抽出したい位相 (1/8)

# 回路の構築
qc_qpe = quantum_phase_estimation(n_bits, target_theta)

# シミュレーションの実行
backend = Aer.get_backend('qasm_simulator')
job = execute(qc_qpe, backend, shots=1024)
result = job.result()
counts = result.get_counts()

# 結果の解析
print(f"Target Theta: {target_theta}")
print(f"Measured Counts: {counts}")

# 最も頻度の高い測定値からthetaを計算
highest_bitstring = max(counts, key=counts.get)
measured_theta = int(highest_bitstring, 2) / (2**n_bits)
print(f"Estimated Theta: {measured_theta}")
```

## 実装の解説と動作検証

### 制御回転の仕組み
コード内の `qc.cp(angle, i, n_precision)` は、制御量子ビット $i$ が $|1\rangle$ のときに、ターゲット量子ビットに回転を与える操作です。量子位相推定では、各ビット $j$ に対して $U^{2^j}$ を作用させる必要があります。これにより、位相 $\theta$ がバイナリ形式の重みとして精度決定レジスタに分散されます。

### 実測結果の確認
上記のコードを、$\theta = 0.125$ （2進数で $0.0010$）として実行した場合、測定結果は `0010` に収束します。

- **入力**: $\theta = 0.125$
- **精度決定レジスタ**: 4ビット
- **期待される出力**: `0010` (2進数) $\rightarrow$ $2/2^4 = 2/16 = 0.125$

もし、$\theta$ が $2^{-n}$ の形（$n$ はビット数以下）で表せる値であれば、理論上、単一の測定結果として正確に得られます。

### 誤差の発生要因
$\theta$ が $2^{-n}$ の倍数ではない場合（例：$\theta = 0.3$）、測定結果は `0100` (0.25) や `0101` (0.3125) のように、真の値に近い複数の状態に確率的に分散します。これは、量子フーリエ変換による離散化による影響です。
