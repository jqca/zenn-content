量子コンピュータのプログラムにおいて、量子回路の計算結果を得るための第一歩は、単一の量子ビットの状態を操作することです。量子コンピュータの真価は、古典的なビット（0か1）では不可能な「重ね合わせ」の状態を作り出し、計算の並列性を活用できる点にあります。

本記事では、量子回路の最も基本的な操作の一つであるHadamard（アダマール）ゲートに焦点を当て、PythonとQiskitを用いて、量子ビットに重ね合わせ状態を作り出し、その確率分布を実測するプロセスを解説します。

## Hadamardゲートの役割

Hadamardゲートは、量子ビットを「0」または「1」の基底状態から、両者が等確率（50%ずつ）で存在する「重ね合わせ状態」へと変換するゲートです。

具体的には、以下の状態遷移を行います。
- |0⟩ → (|0⟩ + |1⟩) / √2
- |1⟩ → (|0⟩ - |1⟩) / √2

この操作によって、量子ビットは「0」と「1」の両方の状態を同時に保持しているような状態になり、量子アルゴリズムにおける並列計算の基盤が作られます。

## 実装：Hadamardゲートによる重ね合わせの生成

それでは、実際にQiskitを用いて、Hadamardゲートを適用した後の状態をシミュレータ上で確認するコードを実装します。

```python
import numpy as np
from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator
from qiskit.visualization import plot_histogram

# 1. 量子回路の定義（1量子ビット）
qc = QuantumCircuit(1)

# 2. Hadamardゲートの適用
# この操作により、|0> 状態から重ね合わせ状態へ遷移する
qc.h(0)

# 3. 測定の追加
# 状態を古典ビットに写し取るために測定を行う
qc.measure_all()

# 4. シミュレータの準備
simulator = AerSimulator()

# 5. 回路の実行
# 試行回数（shots）を1024回に設定
job = simulator.run(qc, shots=1024)
result = job.result()

# 6. 結果の取得
counts = result.get_counts(qc)

print("測定結果（ビット列: 回数）:", counts)
```

## 結果の解析と確率分布の確認

上記のコードを実行すると、出力は以下のような形式になります（実行環境により数値は微増減します）。

```text
測定結果（ビット列: 回数）: {'0': 512, '1': 51deg}
```

この結果から、測定されたビット列「0」と「1」の出現頻度が、ほぼ 50% ずつに収束していることが確認できます。

ここで、Hadamardゲートを適用する前の状態（初期状態 |0⟩）と、適用後の状態を比較してみましょう。もしHadamardゲートを適用せずに測定を行えば、結果は常に「0」となります。Hadamardゲートによってのみ、量子的な確率のゆらぎ、すなわち「重ね合わせ」による結果の分散が生まれます。

## 実装のポイント：測定の本質

量子回路における「測定」は、不可逆なプロセスです。重ね合わせ状態にある量子ビットに測定を行うと、波束の収縮が起こり、必ず「0」または「1」のいずれかの確定的な値として観測されます。

実装上の注意点として、シミュレーションにおける `shots`（試行回数）の重要性があります。量子計算の性質上、1回の測定ではたった1つのビット列しか得られません。そのため、統計的な確率分布（期待値）を把握するためには、数千回から数万回の試行を繰り返す必要があります。

今回の実装では `shots=1024` としており、これは量子ビットの確率的な振る舞いを、古典的な統計量として捉え直すための最小限のプロセスです。

## まとめ

本記事では、Hadamardゲートを用いた量子ビットの重ね合わせ生成について、Qiskitを用いた実装を通じて解説しました。

- Hadamardゲートは、基底状態を重ね合わせ状態へ変換する。
- 重ね合わせ状態の測定結果は、試行回数を増やすことで理論的な確率（50:50）に収束する。
- 量子アルゴリズムの構築において、このゲートは「計算の並列性」を生み出す起点となる。

量子コンピュータのプログラミングは、こうしたゲート操作の積み重ねによって、複雑なアルゴリズムへと発展していきます。
