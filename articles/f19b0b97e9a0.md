## 導入：グラフ構造と量子計算の親和性

グラフ構造のデータ（SNSの繋がり、分子構造、交通ネットワークなど）を扱う際、従来のグラフニューラルネットワーク（GNN）は、ノードの特徴量とエッジの接続関係をメッセージパッシングによって集約していく手法が主流です。

しかし、グラフの次元が増大するにつれ、古典的な計算リソースでは特徴量の集約や高次元な相互作用の計算が困難になる課題があります。ここで期待されているのが、量子計算による高次元特徴空間への写像です。量子回路を用いることで、ノードの情報を量子状態へとエンコードし、量子ビット間の相互作用を通じてグラフのトポロジーを反映した特徴抽出を行う「量子グラフニューラルネットワーク（QGNN）」の実装手法を解説します。

## 量子グラフエンコーディングの考え方

QGNNの実装において最も重要なのは、グラフの隣接行列（Adjacency Matrix）やノード特徴量を、どのように量子回路のパラメータや状態に変換するかという点です。

本記事では、以下のステップで実装を進めます。

1.  **データ準備**: グラフ構造（ノード数とエッジ）の定義。
2.  **量子エンコーディング**: ノード特徴量を回転ゲート（$R_y$ゲート等）の角度として量子回路に注入。
3.  **量子メッセージパッシング**: 量子回路のレイヤー（Ansatz）を通じて、ノード間の情報を量子的な重ね合わせ状態の中で伝播させる。
学術的には、隣接行列の要素を量子回路の結合強度（Entangling layerの制御）に反映させる手法が有力です。

## 実装：Qiskitを用いたQGNNのプロトタイプ

ここでは、最小構成のグラフ（2ノード）を対象に、Qiskitを用いてノード特徴量を量子回路に反映させるコードを作成します。

```python
import numpy as np
from qiskit import QuantumCircuit
from qiskit.circuit import Parameter
from qiskit_aer import AerSimulator

def create_qgnn_layer(num_nodes, adj_matrix, node_features):
    """
    量子グラフレイヤーの構築
    adj_matrix: 隣接行列 (num_nodes x num_nodes)
    node_features: 各ノードの特徴量 (num_nodes)
    """
    # 量子ビット数はノード数に合わせる
    qc = QuantumCircuit(num_nodes)

    # 1. Node Feature Encoding (Feature Map)
    # 各ノードの特徴量をRyゲートの回転角として適用
    for i in range(num_nodes):
        qc.ry(node_features[i], i)

    # 2. Quantum Message Passing (Entanglement Layer)
    # 隣接行列の重みに基づいてCNOTゲートを適用
    for i in range(num_nodes):
        for j in range(i + 1, num_nodes):
            if adj_matrix[i][j] > 0:
                # エッジが存在する場合、量子的な相互作用（CNOT）を導入
                # 重みを制御回転ゲートの角度に反映させる例
                qc.cx(i, j)
                qc.rz(adj_matrix[i][j], j)

    return qc

# テストデータの設定
# 2ノードのグラフ: ノード0とノード1が接続されている
adj = np.array([[0, 1],
                [1, 0]])
features = np.array([0.5, 1.2]) # ノードごenessの初期特徴量

# 量子回路の生成
qgnn_circuit = create_qgnn_layer(2, adj, features)

# シミュレーション実行
simulator = AerSimulator()
# 測定レイヤーの追加
qgnn_circuit.measure_all()

# 実行結果の確認
job = simulator.run(qgnn_circuit, shots=1024)
result = job.result()
counts = result.get_counts()

print("量子回路の構成:")
print(qgnn_circuit.draw())
print("\n測定結果（ビット文字列の出現回数）:")
print(counts)
```

## コードの解説と動作原理

### 1. エンコーディング層
`qc.ry(node_features[i], i)` の部分では、古典的な特徴量（スカラー値）を、量子ビットのブロッホ球上の回転角へと変換しています。これにより、ノードの属性が量子状態の振幅や位相として表現されます。

### 2. メッセージパッシング（Entanglement）
グラフにおける「メッセージの伝達」を、量子ビット間の量子もつれ（Entanglement）として実装しています。`qc.cx(i, j)` を用いることで、ノード $i$ の状態がノード $j$ の状態に影響を与える状態を作り出します。隣接行列の重み $A_{ij}$ を `rz` ゲートのパラメータとして利用することで、エッジの強弱を量子位相の差として表現しています。

### 3. 実行結果の解釈
出力される `counts` は、量子回路を通った後の「グラフの埋め込み（Embedding）」の結果を示しています。このビット分布を、後続の古典的な全結合層（Dense Layer）に入力することで、グラフ分類タスクなどの学習が可能になります。

## 実装上の留意点

このプロトタイプは、ノード数を量子ビット数に直接対応させています。大規模なグラフを扱う場合、量子ビット数が不足するため、以下の手法を組み合わせる必要があります。

*   **Graph Partitioning**: グラフを小さなサブグラフに分割し、それぞれの部分グラフに対して量子回路を適用する。
*   **Hybrid Approach**: ノードの集約（Aggregation）までは古典的なGNNで行い、高次元な特徴抽出（Embedding）のみを量子回路（Quantum Embedding）に委ねる。
