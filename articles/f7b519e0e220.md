===導入===
量子コンピュータの核心的な能力の一つは、量子状態の重ね合わせを利用した「サンプリング」にあります。量子回路を実行した結果、測定によって得られるビット列は、量子状態の振幅の二乗（Bornの規則）に従った確率分布に従います。

このサンプリング技術は、生成モデルの学習や、モンテカルロ・シミュレーションの量子加速、さらには量子機械学習における特徴量生成など、幅広い応用範囲を持っています。本記事では、Qiskitを用いて、特定の確率分布（ベル状態の測定結果）を生成する回路を実装し、その振幅がどのように観測結果に反映されるかを、実際のコードを通じて解析します。

## 量子サンプリングの原理
量子回路におけるサンプリングは、以下のプロセスで行われます。

1. 量子状態の準備：ゲート操作（Hadamardゲート、CNOTゲート等）により、特定の振幅を持つ状態を作成する。
2. 測定：基底状態（$|0\rangle, |1\rangle$）への射影を行う。
3. Bornの規則：状態 $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$ に対して、状態 $|0\rangle$ が観測される確率は $|\alpha|^2$、状態 $|1\rangle$ が観測される確率は $|\beta|^2$ となる。

ここでは、最も基本的なサンプリングの対象として、2量子ビットの最大絡み合い状態（ベル状態）を対象にします。

## 実装：ベル状態の生成と確率分布の検証

PythonとQiskitを用いて、ベル状態 $|\Phi^+\rangle = \frac{1}{\sqrt{2}}(|00\rangle + |11\rangle)$ を生成し、測定結果の頻度をカウントするコードを実装します。

```python
import numpy as np
from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator
from qiskit.visualization import plot_histogram

def create_bell_circuit():
    # 2量子ビット、2古典ビットの回路を作成
    qc = QuantumCircuit(2, 2)
    
    # Hadamardゲートを0番目の量子ビットに適用
    # これにより |0> -> (|0> + |1>) / sqrt(2) となる
    qc.h(0)
    
    # CNOTゲートを適用 (制御ビット: 0, ターゲットビット: 1)
    # これにより |00> + |10> の状態が |00> + |11> に変化する
    qc.cx(0, 1)
    
    # 測定
    qc.measure([0, 1], [0, 1])
    
    return qc

# 回路の構築
circuit = create_bell_circuit()

# シミュレータの準備
simulator = AerSimulator()

# 実行（試行回数：1024回）
shots = 1024
job = simulator.run(circuit, shots=shots)
result = job.result()

# 測定結果の取得
counts = result.get_counts()

print(f"測定結果のカウント: {counts}")

# 結果の解析
for bitstring, count in counts.items():
    probability = count / shots
    print(f"Bitstring: {bitstring}, Probability: {probability:.4f}")
```

## 結果の解析と考察

上記のコードを実行すると、出力は以下のようになります（実行環境により微細な差はありますが、理論値に収束します）。

```text
測定結果のカウント: {'00': 520, '11': 504}
Bitstring: 00, Probability: 0.5078
Bitstring: 11, Probability: 0.4922
```

### 実行結果のポイント
1. **振幅の二乗への収束**: 理論上、ベル状態の各基底の確率は 0.5 です。1024回の試行において、出力された確率（0.5078や0.4922）がこの理論値に近いことが確認できます。
2. **禁止された状態の不在**: 回路構成上、`01` や `10` という状態が発生する確率は、理想的な計算においては 0 です。サンプリング結果にこれらが含まれていない（あるいは極めて低い）ことは、回路が正しくベル状態を生成していることを示します。

## 応用への発展：確率分布の制御
量子サンプリングの応用として、量子回路のパラメータ（回転角 $\theta$）を変化させることで、特定の確率分布を意図的に生成する手法があります。これは「量子変分回路」の基礎となる考え方です。

例えば、`qc.ry(theta, 0)` のように $Y$ 軸回転ゲートを使用すると、測定結果の比率を $\cos^2(\theta/2)$ と $\sin^2(\theta/2)$ の間で制御できます。この「回路のパラメータ操作」と「サンプリング」の組み合わせが、AI×量子における生成モデルの核となります。

- 測定結果のカウント比率は、Bornの規則に従い、量子状態の振幅の二乗に収束する。
