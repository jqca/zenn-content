## 導入：量子カーネル法の仕組みと期待される役割

量子機械学習（QML）の分野において、現在最も実装が進んでおり、かつ古典的な機械学習との比較が容易な手法の一つが「量子カーネル法」です。

量子カーネル法の本質は、入力データを量子状態へと写像（Feature Map）し、その量子状態間の類似度を「量子カーネル」として計算することにあります。古典的なサポートベクターマシン（SVM）が、高次元のカーネル関数を用いてデータの非線形な境界を学習するように、量子カーネル法では量子回路を用いることで、古典コンピュータでは計算が困難な高次元の特徴空間（量子ヒルベルト空間）を探索します。

本記事では、IBM Quantumが提供するQiskitを用い、2次元のデータセットを量子回路によって高次元へ写像し、量子カーネルを用いた分類器を実装するプロセスを解説します。

## データの準備と量子特徴写像（Feature Map）

量子カーネル法を実装する上で最も重要なステップは、古典的なデータ $x$ を量子回路のパラメータとして埋め込む「量子特徴写像」の設計です。

ここでは、もっとも標準的な `ZZFeatureMap` を使用します。このマップは、データの各要素だけでなく、要素間の相互作用（相関）を量子ゲートの回転角として取り込むことができるため、より複雑な特徴空間を構築できます。

```python
import numpy as np
import matplotlib.pyplot as plt
ally from qiskit.circuit.library import ZZFeatureMap
from qiskit_machine_learning.kernels import TrainableFidelityQuantumKernel
from qiskit_algorithms.utils import algorithm_globals
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.svm import SVC

# 再現性のためのシード設定
algorithm_globals.random_seed = 42

# 1. データセットの生成（2次元の月型データ）
X, y = make_moons(n_samples=50, noise=0.1, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# 2. 量子特徴写像の定義
# 2次元データを扱うため、2量子ビットを使用
num_qubits = 2
feature_map = ZZFeatureMap(feature_dimension=num_qubits, reps=2, entanglement='linear')

# 特徴写像の回路構造を確認（最初の数ステップを表示）
print(feature_map.decompose().draw())
```

## 量子カーネルの計算と学習

次に、作成した `ZZFeatureMap` を用いて、量子状態の重なり（Fidelity）を計算するカーネルを構築します。Qiskit Machine Learningの `FidelityQuantumKernel` を使用すると、量子回路の実行結果からカーネル行列（Kernel Matrix）を直接算出できます。

このカーネル行列は、トレーニングデータ間の「似ている度合い」を表す $N \times N$ の行列となります。

```python
from qiskit_machine_learning.kernels import FidelityQuantumKernel
from qiskit.primitives import Sampler

# 3. 量子カーネルの構築
# Samplerを用いて、量子状態の重なりを計算する
sampler = Sampler()
quantum_kernel = FidelityQuantumKernel(feature_map=feature_map, sampler=sampler)

# 4. 量子カーネル行列の計算
# 学習データに対するカーネル行列を作成
matrix_train = quantum_kernel.evaluate(x_vec=X_train)

print(f"Kernel matrix shape: {matrix_train.shape}")
```

ここでは、古典的なSVM（Support Vector Machine）に、この量子カーネル行列を渡して学習を行います。Scikit-learnの `SVC` は `kernel='precomputed'` という引数を取るため、計算済みの量子カーネル行列をそのまま入力として使用できます。

```python
# 5. 古典SVMへの量子カーネルの適用
# プリコンピュートされたカーネルを使用するように設定
qsvc = SVC(kernel='precomputed')
qsvc.fit(matrix_train, y_train)

# 6. テストデータに対するカーネル行列の計算
# テストデータと学習データの相互作用を計算
matrix_test = quantum_kernel.evaluate(x_vec=X_test, y_vec=X_train)

# 7. 予測と精度評価
y_pred = qsvc.predict(matrix_test)
accuracy = np.mean(y_pred == y_test)

print(f"Test Accuracy: {accuracy * 100:.2f}%")
```

## 実装のポイントと考察

この実装における核心は、`quantum_kernel.evaluate(x_vec=X_test, y_vec=X_train)` の部分です。

量子カーネル法において、テストフェーズでは「テストデータ」と「学習データ」のペアに対して、それぞれの量子状態の重なりを計算する必要があります。この行列の形状は `(テストデータの数, 学習データの数)` となります。ここを誤ると、古典的なSVMの入力形式と一致せず、エラーの原因となります。

### 量子カーネル法の限界と課題

実装上で注意すべき点は以下の通りです。

1. **計算コスト**: データの数 $N$ に対して、カーネル行列の計算量は $N^2$ に比例します。量子デバイスでの実行（あるいはシミュレータでの実行）を考慮すると、データ数が増大した際の実行時間の増大が極めて顕著です。
2. **サンプリング誤差**: `Sampler` を用いた計算では、ショット数（測定回数）に依存する統計的なノイズが含まれます。ショット数が不足すると、カーネル行列の値が不安定になり、分類精度に悪影響を及ぼします。
3. **特徴写像の設計**: `ZZFeatureMap` は強力ですが、データの構造に対して適切でない写像を選択してしまうと、量子的な優位性を得ることができません。
