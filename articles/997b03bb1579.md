量子コンピュータのアルゴリズムを構築する際、単一の量子ビットを操作するだけでは、量子的な計算の核心である「量子ビット間の相関」を生み出すことはできません。量子ゲートのなかでも、ある量子ビットの状態に応じて別の量子ビットの操作を決定する「制御ゲート」は、計算の複雑性を構築するために不可脱な要素です。

本記事では、PythonとQiskitを用い、最も基本的な制御ゲートである「制御NOTゲート（CNOTゲート）」の実装方法と、それによって量子ビット間にどのような状態が形成されるのかを具体的に解説します。

## 制御NOTゲート（CNOT）の仕組み

CNOTゲートは、2つの量子ビット（制御ビットと標的ビット）を入力とし、制御ビットの状態に応じて標的ビットの状態を反転させるゲートです。

- 制御ビットが $|0\rangle$ のとき：標的ビットは変化しない
- 制御ビットが $|1\rangle$ のとき：標的ビットを反転させる（NOT操作）

この操作の重要な点は、制御ビットが「重ね合わせ状態」にある場合に、標的ビットも制御ビットと相関した（もつれた）状態になることです。

## Qiskitによる実装手順

実際に、1つの量子ビットをアダマールゲート（Hゲート）で重ね合わせ状態にし、その後にCNOTゲートを適用して、ベル状態（最大もつれ状態）を作成するコードを実装します。

```python
import numpy as np
from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator
from qiskit.visualization import plot_histogram

# 1. 量子回路の定義（2量子ビット）
qc = QuantumCircuit(2)

# 2. 制御ビット(q0)をアダマールゲートで重ね合わせ状態にする
# |0> -> (|0> + |1>) / sqrt(2)
qc.h(0)

# 3. CNOTゲートの適用
# 制御ビット: q0, 標的ビット: q1
qc.cx(0, 1)

# 4. 測定の準備
qc.measure_all()

# 5. シミュレータの実行
simulator = AerSimulator()
job = simulator.run(qc, shots=1024)
result = job.result()
counts = result.get_counts()

# 6. 結果の表示
print("測定結果（ビット列: 回数）:", counts)
```

## 実行結果の解析

上記のコードを実行すると、出力は以下のようになります。

```text
測定結果（ビット列: 回数）: {'00': 512, '11': 512}
```
※実行環境により、数値は多少の揺らぎ（統計的な誤差）を含みます。

この結果は、測定されたビット列が「00」または「11」のみであり、「01」や「10」が観測されていないことを示しています。これは、制御ビットと標的ビットが「ベル状態」と呼ばれる、強い相関（量子もつれ）を持った状態になったことを意味します。

## ゲートの動作フロー

回路の各ステップで、量子状態がどのように遷移しているかを追います。

1. **初期状態**: $|00\rangle$
2. **Hゲート適用後**: $\frac{1}{\sqrt{2}}(|0\rangle + |1\rangle) \otimes |0\rangle = \frac{1}{\sqrt{2}}(|00\rangle + |10\rangle)$
3. **CNOTゲート適用後**: $\frac{1}{\sqrt{2}}(|00\rangle + |11\rangle)$

CNOTゲートが適用された際、制御ビットが $|1\rangle$ のケースにおいて、標的ビットの $|0\rangle$ が $|1\rangle$ へと反転しています。その結果、両方のビットが同じ値をとる状態、すなわち「一方が0ならもう一方も必ず0、一方が1ならもう一方も必ず1」という相関が形成されました。

## 制御ゲートの応用

CNOTゲートは、単体での利用にとどまらず、以下のような高度なアルゴリズムの構成要素となります。

- **量子テレポーテーション**: 量子状態を別の量子ビットへ転送する際の、もつれ状態の作成。
- **Groverのアルゴリズム**: オラクル（解を特定する回路）の構築における、条件付き反転操作。
- **量子エラー訂正**: 補助量子ビットを利用して、データの論理的な状態を保護するための符号化。

量子回路設計においては、いかにしてこれらの制御ゲートを組み合わせ、計算したい問題の論理構造を量子ゲートの列へと落とし込むかが鍵となります。
