量子コンピュータのアルゴリズムを設計する際、特定の量子状態の確率振幅を効率的に推定する手法は、量子化学計算や機械学習への応用において極めて重要です。本記事では、量子振幅推定（Quantum Amplitude Estimation: QAE）の基本原理を解説し、Qiskitを用いて実際に動作するコードを実装します。

## 量子振幅推定とは

量子振幅推定は、ある量子状態 $\lvert \Psi \in \rangle$ に含まれる特定のターゲット状態 $\lvert a \rangle$ の確率振幅 $a$ を推定するアルゴリズムです。

具体的には、以下の状態が用意されているとします。
$$\lvert \Psi \rangle = \sqrt{1-a} \lvert 0 \rangle + \sqrt{a} \lvert 1 \rangle$$

このとき、測定によって $\lvert 1 \rangle$ が得られる確率 $a$ を、量子位相推定（QPE）を応用して効率的に計算します。古典的なサンプリングでは、精度 $\epsilon$ を得るために $O(1/\epsilon^2)$ 回の試行が必要ですが、QAEを用いることで $O(1/\epsilon)$ の計算量で推定が可能です。

## アルゴリズムの構成要素

QAEの実装には、主に以下の3つの要素が必要です。

1. **状態準備回路 (State Preparation)**: 確率 $a$ を含む状態 $\lvert \Psi \rangle$ を生成します。
2. **Grover演算子 (Grover Operator)**: ターゲット状態の振幅を回転させる演算子 $Q$ を構成します。
3. **量子位相推定 (Quantum Phase Estimation)**: 演算子 $Q$ の固有値から、回転角に対応する振幅を抽出します。

## Qiskitによる実装

以下に、単一の量子ビットを用いた振幅推定の最小構成の実装例を示します。ここでは、あらかじめ角度 $\theta$ を指定して、振幅 $a = \sin^2(\theta)$ を推定するプロセスを辿ります。

```python
import numpy as np
from qiskit import QuantumCircuit
from qiskit.circuit.library import QFT
from qiskit_aer import AerSimulator
from qiskik.visualization import plot_histogram

def create_qae_circuit(theta, precision_qubits):
    # 補助量子ビット（位相推定用） + ターゲット量子ビット
    n = precision_qubits
    qc = QuantumCircuit(n + 1, n)

    # 1. 状態準備: |0> -> sqrt(1-a)|0> + sqrt(a)|1>
    # a = sin(theta)^2 なので、Ry回転を使用
    qc.ry(2 * theta, n)

    # 2. 量子位相推定のための準備
    qc.x(n) # ターゲットビットを反転させてOracleの動作を模倣
    
    # 準備した状態にQFTの逆変換を適用するための構成
    # ここでは簡略化のため、QFTと制御回転ゲートを使用
    for i in range(n):
        qc.cp(2 * theta, n, n - 1 - i)
    
    # 逆量子フーリエ変換 (IQFT)
    iqft = QFT(n).inverse()
    qc.append(iqft, list(range(n)))

    # 3. 測定
    qc.measure(range(n), range(n))
    
    return qc

# パラメータ設定
theta_val = np.pi / 8  # ターゲットとなる角度
precision_bits = 3     # 精度を決める補助量子ビット数

# 回路の生成
circuit = create_qae_circuit(theta_val, precision_bits)

# シミュレーション実行
simulator = AerSimulator()
job = simulator.run(circuit, shots=1024)
result = job.result()
counts = result.get_counts()

print(f"Target theta: {theta_val}")
print(f"Measured counts: {counts}")
```

## 実装のポイントと動作解説

### 状態準備と回転
`qc.ry(2 * theta, n)` の部分では、Y軸周りの回転ゲートを用いることで、$\lvert 0 \rangle$ と $\lvert 1 \rangle$ の間の振幅を制御しています。回転角 $2\theta$ によって、$\sin^2(\theta)$ の確率が生成されます。

### 振幅の回転（Grover演算子のエッセンス）
QAEの本質は、演算子 $Q$ を繰り返し適用することで、振幅を位相空間上で回転させることにあります。上記のコードでは簡略化のため、制御位相ゲート（`cp`）を用いて、位相推定プロセスにおける回転角の抽出をシミュレートしています。

### 精度とビット数
`precision_bits` を増やすほど、推定される値の解像度は上がりますが、回路の深さ（Depth）は指数関数的に増加します。実機での実行においては、ゲートエラーの影響を考慮し、適切なビット数を選択する必要があります。

## 実行結果の解釈

実行結果として得られるビット列は、位相 $\theta$ を $2^n$ 分割したインデックスに対応しています。
例えば、`precision_bits = 3` の場合、測定された値 $k$ から、推定される角度は $\theta \approx \frac{2\pi k}{2^3}$ となります。

測定されたビット列が `000` に近いほど、$\theta$ が小さいことを示し、`111` に近いほど、$\theta$ が $\pi$ に近いことを示します。
