=== 導入 ===
量子コンピュータが特定の計算領域で優位性を示す可能性を秘めている理由は、量子状態の重ね合わせと干渉を利用して、複雑な計算を効率的に行う能力にあります。その中でも、量子位相推定（Quantum Phase Estimation: QPE）は、量子アルゴントリズムの基盤となる極めて重要な手法です。

QPEの目的は、あるユニタリ演算子 $U$ と、その固有状態 $|\psi\rangle$ が与えられたとき、方程式 $U|\psi\rangle = e^{2\pi i \theta}|\psi\rangle$ を満たす位相 $\theta$ を推定することです。この $\theta$ は、量子化学計算におけるエネルギー準位の特定や、シャール・アルゴリズム（Shor's algorithm）における周期発見の核心部分を担います。

本記事では、PythonとQiskitを用い、実際に動作するコードを通じて、QPEの仕組みを実装レベルで解説します。

=== アルゴリズムの構造 ===
QPEを実装するためには、主に2つのレジスタが必要です。

1. **精度決定レジスタ（ancilla qubits）**: 推定したい位相 $\theta$ の精度を決定するレバイ。ビット数が多いほど、より高精度な $\theta$ を得られます。
2. **状態レジスタ（target qubits）**: ユニタリ演算子 $U$ が作用する、固有状態 $|\psi\rangle$ を保持するレジスタ。

アルゴリズムの流れは以下の通りです。

1. **初期化**: 精度レジスタを $|0\rangle$ 状態に、状態レジスタにターゲットとなる状態 $|\psi\rangle$ を用意します。
2. **重ね合わせの作成**: 精度レジスタにアダマールゲートを適用し、すべての基底状態の重ね合わせを作ります。
3. **制御ユニタリ演算の適用**: 精度レジスタの各ビットに対して、時間ステップ $2^j$ ごとに制御 $U^{2^j}$ 演算を適用します。これにより、位相情報が精度レジスタの位相として「エンコード」されます。
4. **逆量子フーリエ変換 (IQFT)**: 位相情報としてエンコードされた値を、計算可能なビット形式（基底状態）に戻すために、量子フーリエ変換の逆変換を適用します。
5. **測定**: 精度レジスタを測定し、得られたビット列から $\theta$ を読み取ります。

=== 実装：Qiskitによる量子位相推定 ===

ここでは、最も基本的なケースとして、回転ゲート $R_z(\phi)$ の位相を推定する実装を行います。$R_z(\phi)$ の固有値は $e^{-i\phi/2}$ です。この $\phi$ を推定することを目標とします。

```python
import numpy as np
from qiskit import QuantumCircuit, Aer, execute
from qiskit.circuit.library import QFT

def quantum_phase_estimation(phi, precision_qubits):
    """
    指定された位相 phi を持つ回転ゲートの位相を推定する回路を構成する
    """
    # 精度レジスタ + ターゲットレジスタ
    n = precision_qubits
    qc = QuantumCircuit(n + 1, n)

    # 1. 精度レジスタにアダマールゲートを適用
    for qubit in range(n):
        qc.h(qubit)

    # 2. ターゲットレジスタを初期化 (例: |1> 状態へ)
    qc.x(n)

    # 3. 制御回転ゲートの適用
    # 位相 theta = phi / (2 * pi) として計算を進める
    for qubit in range(n):
        # 制御演算子 U^{2^qubit} を適用
        # ここでは 2*pi*theta = phi に相当する回転を行う
        angle = phi * (2**(qubit))
        # 制御Rzゲートの適用（Qiskitのcpゲートを使用）
        # 注: 制御回転の角度調整が必要
        qc.cp(angle, qubit, n)

    # 4. 逆量子フーリエ変換 (IQFT) の適用
    qc.append(QFT(n).inverse(), list(range(n)))

    # 5. 測定
    qc.measure(list(range(n)), list(range(n)))
    
    return qc

# パラメータ設定
phi_target = 2 * np.pi * 0.375  # 推定したい位相 (theta = 0.375)
precision = 4  # 精度レジスタのビット数

# 回路の構築
qc = quantum_phase_estimation(phi_target, precision)

# シミュレータでの実行
simulator = Aer.get_backend('qasm_simulator')
job = execute(qc, simulator, shots=1024)
result = job.result()
counts = result.get_counts()

# 結果の表示
print(f"Target theta: 0.3tal 0.375")
print(f"Measured counts: {counts}")

# 測定結果からthetaを復元
for outcome, count in counts.items():
    # 2進数文字列を整数に変換
    val = int(outcome, 2)
    # 2^n で割って theta を算出
    theta_est = val / (2**precision)
    print(f"Outcome: {outcome} -> Estimated theta: {theta_est}")
```

=== 実装のポイント解説 ===

#### 1. 制御回転ゲートの役割
コード内の `qc.cp(angle, qubit, n)` は、精度レジスタの `qubit` 番目が $|1\rangle$ のときのみ、ターゲットレジスタに回転を適用する演算です。$2^j$ 倍の回転を順次適用することで、位相 $\theta$ の各ビットが精度レジスタの各量子ビットにビットシフトされた状態で書き込まれます。

#### 2. 逆量子フーリエ変換 (IQFT) の重要性
制御ゲートを適用した直後の状態は、位相が「周波数」の形でエンコードされています。これを私たちが読み取れる「ビット値」に変換するのが IQFT です。これを行わないと、測定結果はランダムな分布になってしまいます。

#### 3. 精度とビット数の関係
精度レジスタのビット数 `precision` を増やすと、推定できる $\theta$ の分解能が上がります。例えば `precision=4` の場合、値は $k/2^4$ （$k$ は整数）のステップでしか得られません。本実装の例では $0.375$ は $3/8 = 6/16$ なので、正しく測定可能です。

=== 実行結果の考察 ===
上記のコードを実行すると、測定結果（Measured counts）として、目標とする $0.375$ に対応するビット列が得られます。

例えば、`outcome` が `0110` と得られた場合：
$6 / 2^4 = 6 / 16 = 0.375$

このように、量子回路を通じて位相成分をビット列として抽出できることが確認できます。

=== まとめ ===
量子位相推定は、量子コンピュータが持つ「位相」という情報を、古典的な「ビット」へと変換するためのブリッジとなるアルゴリズムです。この手法の理解は、量子化学、量子機械学習、そして量子ファクター分解アルゴリズムを理解するための第一歩となります。

実装においては、制御ゲートの回転角の正確な制御と、IQFTによる情報の復元が鍵となります。
