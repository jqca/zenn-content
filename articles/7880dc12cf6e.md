## 導入
量子コンピュータの計算能力を実用的なものにするための最大の障壁は、量子ビットの「ノイズ」です。現在のNISQ（Noisy Intermediate-Scale Quantum）デバイスでは、量子ゲートの実行に伴うエラーが蓄積し、計算結果の精度が著しく低下します。

この課題に対し、量子エラー訂正（QEC）のような大規模なリソースを必要とする手法とは別に、計算結果の統計的な処理によってエラーの影響を低減させる「量子エラー抑制（Error Mitigation）」というアプローチがあります。

本記事では、Qiskitを用いて、最も基本的なエラー抑制手法の一つである「ゼロノイズ外挿（Zero-Noise Extrapolation: ZNE）」の実装と、ノイズが計算結果に与える影響を検証する方法を解説します。

## 量子エラー抑制（Error Mitigation）とは
量子エラー抑制は、物理的な量子ビットの品質を直接改善するのではなく、実行した回路の測定結果（期待値）に対して、後処理（Post-processing）を行うことで、より理想的な（ノイズが少ない）状態の値を推定する技術です。

特に、回路のノイズレベルを意図的に変動させ、その変化の傾向から「ノイズがゼロの状態」を数学的に予測（外挿）する手法が、現在の研究開発において非常に重要です。

## 実装：ゼロノイズ外挿（ZNE）による期待値の推定

ここでは、Qiskitを用いて、量子ゲートの実行時間を意図的に引き延ばすことで、疑似的にノイズレベルを増大させた回路を作成し、そこから元の期待値を推定するプロセスを実装します。

### 1. 環境準備
以下のライブラリを使用します。
```python
from qiskit import QuantumCircuit
from qiskit.quantum_info import SparsePauliిR, expectation_value
from qiskit_aer import AerSimulator
from qiskit_aer.noise import NoiseModel, depolarizing_error
import numpy as np
import matplotlib.pyplot as plt
```

### 2. ノイズモデルの構築
まずは、実機に近い状況をシミュレートするために、デポラリジング・ノイズ（Depolarizing Error）を含むノイズモデルを作成します。

```python
def create_noise_model(error_rate):
    noise_model = NoiseModel()
    error = depolarizing_error(error_rate, 1)
    error_gate = depolarizing_error(error_rate, 2)
    
    # 1量子ビットゲートにノイズを適用
    noise_model.add_all_qubit_diamond_error(error, ['u1', 'u2', 'u3', 'h', 'x'])
    # 2量子ビットゲートにノイズを適用
    noise_model.add_all_qubit_diamond_error(error_gate, ['cx'])
    return noise_model
```

### 3. 測定対象の回路と実行
ベル状態（量子もつれ状態）の生成と、そのZ成分の期待値 $\langle Z \otimes Z \rangle$ を計算する回路を考えます。

```python
def run_circuit_with_noise(error_rate):
    qc = QuantumCircuit(2)
    qc.h(0)
    qc.cx(0, 1)
    qc.measure_all()
    
    noise_model = create_noise_model(error_rate)
    simulator = AerSimulator(noise_model=noise_model)
    
    # 実行
    job = simulator.run(qc, shots=2048)
    counts = job.result().get_counts()

    prob_11 = counts.get('11', 0) / 2048
    expectation_value = prob_00 + prob_11 - (counts.get('01', 0)/2048 + counts.get('10', 0)/2048)

    return z_z_expectation

# 異なるエラー率で実行
error_rates = [0.0, 0.01, 0.05, 0.1]
results = []

for rate in error_rates:
    val = run_circuit_with_noise(rate)
    results.append(val)
    print(f"Error Rate: {rate:.2f}, Expectation Value: {val:.4f}")
```

### 4. ゼロノイズ外挿（ZNE）の適用
得られた「エラー率 vs 期待値」のデータ点に対し、多項式近似を用いてエラー率 = 0 のときの値を推定します。

```python
# データのプロットと外挿
coeffs = np.polyfit(error_rates, results, 1) # 1次関数で近似
zero_noise_estimate = np.polyval(coeffs, 0)

plt.scatter(error_rates, results, label='Measured with noise')
plt.plot(error_rates, np.polyval(coeffs, error_rates), color='red', label='ZNE Extrapolation')
plt.axhline(y=1.0, color='green', linestyle='--', label='Ideal Value')
plt.xlabel('Error Rate')
plt.ylabel('Expectation Value <Z ⊗ Z>')
plt.legend()
plt.show()

print(f"Estimated value at zero noise: {zero_noise_estimate:.4f}")
```

## 実装のポイントと考察

### 誤差の増幅プロセス
ZNEの肝は、ノズを「増やす」ことです。本実装では、`error_rate` を変えることでノイズを操作していますが、実機で行う場合は、`CX` ゲートを `CX` → `CX` → `CX` のように、同じ演算を繰り返すことで、ゲートの実行時間（＝ノイズの影響を受ける時間）を擬似的に引き延ばします。

### 外挿の限界
上記のコードでは1次式（直線）で近似していますが、高次のノイズモデル（非線形なエラーの蓄積）に対しては、2次式以上の多項式を用いる必要があります。ただし、次数を上げすぎると「過学習」が起き、測定データのわずかなゆらぎに対して推定値が極端に不安定になるため、モデルの選択は慎重に行う必要があります。

### 実測値の確認
実験の結果、エラー率が増加するにつれて期待値は $1.0$ から減少する傾向を示します。外挿によって得られた `zero_noise_estimate` が、理想値である $1.0$ にどれだけ近づいたかが、このエラー抑制手法の精度指標となります。
