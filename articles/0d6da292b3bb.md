AI×量子コンピューティングの基礎となる量子回路の構成要素において、最も基本的かつ重要な操作が「重ね合わせ（Superposition）」の生成です。

古典的なビットは「0」または「1」のいずれかの状態しか取れませんが、量子ビット（qubit）は、0と1が特定の確率で混ざり合った状態を作ることができます。本記事では、Qiskitを用いてHadamard（アダマール）ゲートを適用し、量子ビットの重ね合わせ状態を実装・観測するプロセスを解説します。

## Hadamardゲートによる状態の変化

量子回路において、初期状態（すべての量子ビットが $|0\rangle$ である状態）から重ね合わせ状態を作るために使用するのがHadamardゲートです。

Hadamardゲートを $|0\rangle$ に適用すると、以下の状態が生成されます。

$$|0\rangle \xrightarrow{H} \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)$$

この状態において、測定を行った際に「0」が得られる確率と「1」が得られる確率は、それぞれ 50% ずつとなります。この「測定するまで結果が確定しない」という性質が、量子計算の並列性の基礎となります。

## Qiskitによる実装

それでは、実際にPythonとQiskitを用いて、Hadamardゲートを適用し、その結果を統計的に確認するコードを書いていきます。

```python
import numpy as np
from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator
from qiskit.visualization import plot_histogram

# 1. 量子回路の定義（量子ビット1つ、古典ビット1つ）
qc = QuantumCircuit(1, 1)

# 2. Hadamardゲートの適用
# 初期状態 |0> に Hゲートを適用し、重ね合わせ状態を作る
qc.h(0)

# 3. 測定の実行
# 量子ビットの状態を古典ビットに格納
qc.measure(0, 0)

# 4. シミュレータのセットアップ
simulator = AerSimulator()

# 5. 実行（1024回の試行）
job = simulator.run(qc, shots=1024)
result = job.result()

# 6. 結果の取得
counts = result.get_counts(qc)
print(f"測定結果のカウント: {counts}")
```

## 実行結果の解析

上記のコードを実行すると、以下のような出力が得られます（実行環境により数値は多少変動します）。

```text
測定結果のカウント: {'0': 512, '1': 512}
```

この結果から、`0` と `1` がほぼ等しい頻度で出現していることが分かります。1024回の試行において、統計的な誤差の範囲内で 50:50 の比率で観測されました。

ここで重要なのは、単に「50%ずつ出る」という結果だけではなく、回路の設計において「特定の確率分布を持つ状態を意図的に作り出している」という点です。

## 回路の可視化

回路の構造を視覚的に確認するために、回路図を出力してみます。

```python
# 回路図の表示
print(qc.draw(output='text'))
```

出力結果：
```text
     ┌───┐┌─┐
q_0: ┤ H ├┤M├
     └───┘└╥┘
c: 1/══════╩═
           0
```
`qc.h(0)` によってHゲートが挿入され、その直後に `qc.measure` による測定操作が行われていることがわかります。

## まとめ

本記事では、Hadamardゲートを用いた量子ビットの重ね合わせ状態の実装を確認しました。

1. 初期状態 $|0\rangle$ にHゲートを適用することで、0と1の確率的な重ね合わせ状態が作れる。
2. 測定を行うと、理論上の確率（50%ずつ）に基づいた結果が統計的に得られる。
3. この「状態の操作」と「測定」の組み合わせが、量子アルゴリズムの最小単位となる。

AI×量子コンピューティングの実装においては、この重ね合わせ状態をどのように制御し、特定の計算結果（確率分布）へ導くかが鍵となります。
