量子コンピュータのアルゴリズムを理解する上で、量子ビットの「重ね合わせ（Superposition）」の状態を制御することは、計算の並列性を引き出すための最も基本的なステップです。

古典的なビットが「0」か「1」のいずれかの状態しか持てないのに対し、量子ビットは両方の状態を確率的に併せ持つことができます。この状態を作り出すために、量子回路において最も頻繁に使用されるのがHadamard（アダマール）ゲートです。

本記事では、PythonとQiskitを用いて、Hadamardゲートを適用する前後の量子状態の変化を、実際にシミュレータ上で実行して確認します。

## Hadamardゲートによる状態の変化

Hadamardゲート（Hゲート）は、基底状態 $|0\rangle$ または $|1\rangle$ に対して作用し、それらを等しい確率で持つ重ね合わせ状態へと変換します。

具体的には、以下の変換が行われます。

- $|0\rangle \rightarrow \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)$
- $|1\rangle \rightarrow \frac{1}{\sqrt{2}}(|0\rangle - |1\rangle)$

この結果、測定を行った際には 0 と 1 がそれぞれ 50% の確率で出現することになります。

## Qiskitによる実装

それでは、実際にQiskitを使用して、1量子ビットの回路を作成し、Hadamardゲートを適用した際の測定結果をシミュレーションしてみましょう。

```python
import numpycases
from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator
from qiskit.visualization import plot_histogram

# 1. 量子回路の作成（1量子ビット、1古典ビット）
qc = QuantumCircuit(1, 1)

# 2. Hadamardゲートの適用
# 初期状態 |0> に Hゲートを適用し、重ね合わせ状態を作る
qc.h(0)

# 3. 測定の実行
qc.measure(0, 0)

# 4. シミュレータの設定と実行
simulator = AerSimulator()
job = simulator.run(qc, shots=1024)
result = job.result()

# 5. 結果の取得
counts = result.get_counts(qc)
print(f"測定結果: {counts}")
```

## 実装の解説

上記のコードで行っているステップは以下の通りです。

1. **回路の定義**: `QuantumCircuit(1, 1)` で、計算に使う量子ビット1つと、測定結果を格納する古典ビット1つを定義しています。
2. **Hゲートの適用**: `qc.h(0)` が、0番目の量子ビットにHadamardゲートを適用する命令です。
3. **測定**: `qc.measure(0, 0)` により、量子ビットの状態を古典ビットへ書き込みます。この瞬間に、重ね合わせ状態は崩れ、特定のビット値（0または1）に確定します。
4. **シミュレーション**: `AerSimulator` を使い、量子回路の動作を古典コンピュータ上でエミュレートします。`shots=1024` とすることで、同じ回路を1024回試行し、確率分布を算出しています。

## 実行結果の確認

このコードを実行すると、以下のような出力が得られます（実行環境により、数値の微差はあります）。

```text
測定結果: {'0': 521, '1': 503}
```

このように、1024回の試行において、'0' と '1' がほぼ 50% ずつの割合で出現していることがわかります。これが、Hadamardゲートによって量子ビットが「重ね合わせ状態」になったことを示す実証的な結果です。

## 重ね合わせの重要性

なぜこの「重ね合わせ」が必要なのでしょうか。

量子アルゴリズムの多くは、初期状態にHadamardゲートを適用して、すべての可能な状態（$2^n$ 通りのビット列）を同時に作り出すことから始まります。例えば、Groverのアルゴリズムや、量子フーリエ変換を用いたアルゴリズムでは、この重ね合わせ状態に対して特定の干渉（Interference）を起こすことで、正解となる確率を増幅させていきます。

Hadamardゲートによる制御を理解することは、量子コンピュータの計算能力の根幹を理解することと同義です。
