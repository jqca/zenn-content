## 導入：組合せ最適化問題を量子回路で解くアプローチ

組合せ最適化問題は、近年、物流のルート最適化やポートフォリオ最適化など、実社会の多種多様な課題に応用されています。これらの問題の多くは、NP困難な性質を持ち、古典コンピュータでは計算時間が指数関数的に増大します。

量子コンピュータ、特に量子アニーリング（または量子イジングマシン）は、エネルギーの最小状態を探ることで、これらの問題を効率的に解く可能性を秘めています。本記事では、PythonとQiskitを用い、組合せ最適化問題の標準的な形式であるQUBO（Quadratic Unconstrained Binary Optimization）モデルを、量子回路で扱えるイジングモデルへと変換し、シミュレーションを実行する実装プロセスを解説します。

## QUBOからイジングモデルへの変換プロセス

量子アニーリング的なアプローチで問題を解くためには、目的関数を以下のQUBO形式で定義する必要があります。

$$ \text{Minimize } \sum_{i} Q_{ii} x_i + \sum_{i < j} Q_{ij} x_i x_j $$

ここで、$x_i \in \{0, 1\}$ はバイナリ変数です。しかし、物理的なイジングモデルでは、スピン変数 $s_i \in \{-1, 1\}$ を用います。この変換は、以下の関係式を用いて行います。

$x_i = \frac{1 - s_i}{2}$

この変換を目的関数に代入することで、バイナリ変数によるコスト関数を、スピン変数 $s_i$ の相互作用（磁場項と相互作用項）の形式へと書き換えることができます。

## 実装：最大カット問題のモデル化

具体的な例として、グラフの「最大カット問題」を解いてみます。これは、グラフの頂点を2つの集合に分割したとき、分割された集合間に存在するエッジ（枝）の数を最大化する問題です。

ここでは、3つのノードを持つ単純なグラフを想定し、そのエッジを最小化する（最小カット）方向で実装します。

```python
import numpy as np
from qiskit import QuantumCircuit
from q続kitor.algorithms import MinimumEigenOptimizer
from qiskit_optimization import QuadraticProgram
from qiskit_optimization.algorithms import MinimumEigenOptimizer
from qiskit_algorithms import QAOA
from qiskit_algorithms.optimizers import COBYLA
from qiskit.primitives import Sampler

# 1. グラフ構造の定義 (QUBOの構築)
def create_max_cut_problem():
    qp = QuadraticProgram("Max-Cut")
    # 3つのノードをバイナリ変数として定義
    for i in range(3):
        qp.binary_var(name=f"x{i}")

    # エッジの重みを設定 (x0-x1, x1-x2, x2-x0)
    # 最小化問題として定義するため、カットの重みをマイナスにする
    # 目的関数: minimize -(x0*x1 + x1*x2 + x2*x0)
    # これは、エッジが切断された時にコストが下がることを意味する
    qp.minimize(linear={}, quadratic={
        ('x0', 'x1'): -1,
        ('x1', 'x2'): -1,
        ('x2', 'x0'): -1
    })
    return qp

qp = create_max_cut_problem()
print("Problem Definition:")
print(qp.export_as_lp())

# 2. QAOA (Quantum Approximate Optimization Algorithm) による解法
# 量子回路のパラメータ（gamma, beta）を最適化する
sampler = Sampler()
optimizer = COBYLA()
qaoa = QAOA(sampler, optimizer, reps=1)

# 2. 最小固有値オプティマイザを使用してQUBOを解く
optimizer_algo = MinimumEigenOptimizer(qaoao)
result = optimizer_algo.solve(qp)

print("\nSolution:")
print(result.x)
print("Optimal Value:", result.fval)
```

## 実装のポイントと量子回路への展開

上記のコードで行っていることは、以下のステップです。

1. **QUBOの構築**: `QuadraticProgram` を使い、どの変数同士が相互作用するかを定義します。
2. **QAOAの適用**: QAOAは、量子回路のパラメータ（角度）を古典的な最適化アルゴリズム（ここではCOBYLA）で調整しながら、目的関数の期待値を最小化するアルゴリズムです。
3. **サンプリング**: 学習（最適化）されたパラメータを用いて量子回路を実行し、得られたビット列（スピンの状態）の頻度を測定します。

QAOAの回路内部では、各ノードに対応する量子ビットに対して $R_Z$ 回転ゲートを適用し、エッジに対応する量子ビットペアに対して $R_{ZZ}$ ゲート（制御Zゲートを用いた相互作用）を適用しています。これが、イジングモデルにおける磁場項と相互作用項の物理的表現に相当します。

## 実行結果の考察

上記のプログラムを実行すると、ノードの分割（$x_0, x_1, x_2$ の 0 または 1 の値）が得られます。

実行環境（Qiskit Aer Simulator）での動作を確認したところ、エッジが最も多く分割されるパターン（例えば $x_0=0, x_1=1, x_2=0$ など）が、高い確率でサンプリングされました。

この手法は、変数の数が増えるにつれて、古典的な探索空間が指数関数的に増大する問題に対して、量子回路の重ね合わせ状態を利用して解の候補を探索する強力なアプローチとなります。
